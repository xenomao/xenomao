# デジラボビューティ 賛助会員 営業リスト ― 1万件 セグメント設計

> 目的：賛助会員（協賛・パートナー）獲得に向けた、美容業界×IT/AIのシナジー企業リストを **合法かつ実用的に** 1万件構築する。
>
> ⚠️ 重要：このリストは「実在企業の検証済みデータ」で埋めるものです。AIによる連絡先の自動生成（=架空データ）は行いません。架空の電話番号・メールは営業に使えないだけでなく、偶然実在する第三者に営業が飛ぶ法的・倫理的リスクがあります。本ファイルは「どの実データ源から、何件ずつ集めるか」の設計図です。

## 1. 全体方針

| 項目 | 内容 |
|---|---|
| 目標件数 | 10,000件（重複除去後） |
| 必須カラム | 会社名 / 住所 / メールアドレス / 担当部署 / 電話番号 |
| 取得原則 | 公開情報・許諾済みデータ・自社収集のみ。スクレイピングは各サイト規約と法令に従う |

| 重複排除キー | 法人番号（あれば）→ 会社名＋電話番号 → ドメイン |

## 3. 推奨データ源（合法）一覧

### 無料・公的
- **国税庁 法人番号公表サイト**（会社名・住所・法人番号が全法人分・無料）
  - Web-API: https://www.houjin-bangou.nta.go.jp/webapi/
  - 一括ダウンロード（都道府県別CSV）: https://www.houjin-bangou.nta.go.jp/download/
  - ※電話・メール・担当部署は**含まれない** → 別途エンリッチが必要
  - 本リポジトリの `prospects/scripts/fetch_houjin_bangou.py` でキーワード抽出可能
- **業界団体の会員名簿**（JNA / AEAJ / JCIA / 各学会 等）：公開範囲を確認のうえ利用
- **Google ビジネスプロフィール / Google Maps Places API**：店舗系（エステ・ネイル・整体）の住所・電話に強い（API利用規約遵守）
- **展示会 出展者一覧**（BeautyWorld Japan, COSME Week, BeautyTech 系）：BtoB（メーカー/ディーラー/IT）に最適

### 有料（許諾済みデータ・正規ルート）
- ランドスケイプ「LBC」/ Baseconnect「Musubu」/ uSonar 等の企業DB（業種・地域・規模で抽出、メール配信可否フラグ付き）
- iタウンページ・各種名鑑データ

## 4. ワークフロー（推奨）

1. **ベース抽出**：国税庁法人番号DB＋Google Places で「会社名・住所・電話」を実データで取得
2. **エンリッチ**：公式サイトから問い合わせ窓口・担当部署・フォームURLを補完
3. **名寄せ・重複排除**：`prospects/scripts/` のユーティリティ＋手作業確認
4. **オプトイン整理**：メール送信可否を行単位で管理（`オプトイン状況` 列）
5. **品質チェック**：サンプリングで電話/URL の到達性を確認してから営業投入

## 5. 法令・コンプライアンス チェックリスト

- [ ] 特定電子メール法：広告メールは原則オプトイン。同意取得記録を保管
- [ ] 個人情報保護法：個人事業主・担当者名は個人情報。利用目的の明示・適正取得
- [ ] 各データ源の利用規約：スクレイピング可否、再配布可否を確認
- [ ] 連絡先の鮮度：定期的な再検証（廃業・移転の反映）
