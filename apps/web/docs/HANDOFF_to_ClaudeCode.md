## 1. ブランド・デザイン仕様（厳守）

### カラートークン
```css
--cream:    #FFFDFB;  /* 下地：明るい白（背景は必ず白基調） */
--cream2:   #F6F1EA;  /* 薄いクリーム */
--ink:      #241F38;  /* 本文の濃い藤墨 */
--ink-soft: #605973;  /* サブテキスト */
--blue:     #5B8DF0;  /* グラデ：青 */
--purple:   #A855F7;  /* グラデ：紫 */
--pink:     #F0467A;  /* グラデ：マゼンタピンク */
--line:     rgba(168,85,247,.18); /* 罫線 */
--line-green:#06C755; /* LINE緑 */
```

### 原則
- **下地は必ず白**。ダーク背景は使わない（`color-scheme: light only` を明示）。
- グラデは「青→紫→ピンク」の波動。**ブラック×ゴールドは永久禁止**。
- 装飾は淡いパステル波動（blur円を低opacityで配置。multiplyは使わない＝暗転防止）。
- 抽象アートのみ。**人物写真・ストック画像・他者著作物は使わない**（権利クリアのSVGのみ）。
- フォント: 見出し `Cormorant Garamond`、和文 `Shippori Mincho`（PDFは Noto Serif CJK JP 代替）。
- **グラデ文字（背景クリップ）はPDF（weasyprint等）で非対応** → PDFではべた塗り `#B0479E` を使う。

## 2. メインLP（digilab-beauty-lp-demo.html）の構造

### 共通ヒーロー
- コピー: 「美容の"品質"を、**育てる場所**。」
- サブ: 「サロンの成長も、業界の信頼も、根っこは同じ『品質』。学びと基準の両輪で支える。」
- 中央に「美質の波動」SVG（中心の光核から波紋が広がるアニメ）。

### 切替タブ（sticky）
```
◉ サロン・個人の方（集客・リピートの悩みに）   ○ 企業・団体の方（品質基準・認証）
```
JSで `pane-salon` / `pane-biz` を出し分け（`.pane.active{display:block}`）。

### pane-salon（B2C・実利・親しみ）
1. **自己診断**（売り込みでなく現在地確認。AIという言葉は出さない）
   - 立場選択: サロン経営者 / 個人セラピスト
   - 各6問。**悩み起点6軸**でスコアリング:
     `[集客, リピート, 単価・指名, 時間・運営, 発信・口コミ, 数字・経営]`
   - 結果: 112点換算スコア + 6軸レーダーチャート(SVG) + ランク + **最弱軸を自動検出**
   - 最弱軸 → 経営ベネフィット言語 + 連動セミナーを提示（下表）
   - データはブラウザ内処理のみ・サーバー送信なし（個情法配慮）
2. **セミナー予告3本**（VOL.1〜3。仮タイトルは下記。AI語は使わない）
3. **公式LINEワンクリック動線**（緑の大ボタンを主役、Instagramは控えめなテキストリンク）
   - 月1,000円表記、「初回セミナー無料ご招待」を訴求

#### 6軸 → 連動セミナーの対応表（結果画面で使用）
| 弱点軸 | 見出し（悩み） | 連動セミナー名 |
|---|---|---|
| 集客 | 新しいお客様の"入口"が足りていないかも | 予約の"入口"を増やす — 安定集客の仕組みづくり |
| リピート | せっかくのお客様が1回で離れているかも | "また来たい"を生む、リピートの仕組みづくり |
| 単価・指名 | 安売りから抜け出せていないかも | 安売りをやめる — 指名と単価を上げる伝え方 |
| 時間・運営 | 雑務に時間を奪われ余裕がないかも | 1日30分の余白をつくる — 事務作業を手放す運営術 |
| 発信・口コミ | 発信が集客につながっていないかも | 反応が変わる — 集客につながるSNS発信のコツ |
| 数字・経営 | "どんぶり勘定"で判断が勘になっているかも | 数字で回すサロン経営 — 見るべき数字と打ち手 |

#### セミナー予告3本（最終セクション固定・仮タイトル＝実物に差替）
- VOL.1（6/21）予約が埋まりやすくなる、エステサロンの"自動集客"のしくみ
- VOL.2（7/19）1日30分の時短ワザ — 事務作業から解放されるサロン運営
- VOL.3（8/23）リピートが続く、お客様カルテの活かし方
- ※「予約が埋まる」「自動集客」等は**景表法の優良誤認リスク**。実装時に「学ぶ内容」基準へ要調整。

### pane-biz（B2B・実利・権威）※「標準」という語は前面に出さない
1. Why: 「自社で大丈夫」では信頼されない時代 → 第三者評価で「選ばれる理由」を証明
2. 導入で得られる3つの価値: 信頼の見える化 / リスク先回り / 差別化
3. 評価フレーム: 112点の「信頼の物差し」（7視点・28項目）
4. 3つの評価レベル: Practitioner / Professional / Master Fellow
5. CTA: 資料請求（企業向けPDFを配布）

## 3. 2階層目 LINEページ（digilab-beauty-line-landing.html）

- ヒーロー: 「その『伸びしろ』、毎月ひとつずつ埋めていく。」（LP診断と接続）
- 友だち追加特典 = **初回セミナー無料ご招待**
- LINE大ボタン文言は全箇所統一: **「公式LINEで無料招待を受け取る」**
- 月1,000円会員の特典3つ（※下記の法務確認を反映のこと）:
  1. 月2回のオンラインセミナー（アーカイブあり）
  2. 提携福利厚生「ベネフィット・ワン」優待（約140万件）※外注契約済み
  3. スマホに持てるNFT会員証（換金性を持たせない=会員証明に限定）
- ネガティブ文言（「いつでもブロック」等）は使わない。「※登録は無料です。」のみ。

### 課金フロー（Stripeは最後に実装予定）
```
LP診断 → 公式LINE友だち追加 → 初回セミナー無料体験
 → （温度MAX）月1,000円継続案内 → Stripe Checkout（月額サブスク JPY1,000）
 → 決済完了 → サンクスページ（digilab-beauty-payment-success.html）→ 会員限定
```
- 決済はStripe側に寄せる（特商法表記・解約導線をStripeで整備）。LINE内決済はしない。
- サンクスページのデザインも作成済み（同じ白基調パステル）。

## 4. ★最重要タスク: 企業向け資料へのガイドライン反映

現在の企業向けPDF（`DigiLabBeauty_企業向けご案内.pdf`）は
「ふわっとした品質評価」止まりで、**"何を守るのか"という規範の実体が無い**のが弱点。

プロジェクト内の既存ガイドライン資産を読み込み、反映してください:
- `美容AI活用ガイドライン_v1.0`（応用層・業界標準・664段落）
- `美容サロン法規コンプライアンスハンドブック_v2.0`（基礎層・816段落）

### 反映すべき核（既存資産より）
**DigiLab AI Code of Practice（10原則）** ← これを企業資料に明示登場させる:
1. 透明性原則（AI生成の明示／EU AI Act準拠）
2. Human-in-the-loop（人間の最終判断義務）
3. 法令遵守の自動化（3層チェックフロー）
4. 説明責任（AI事業者への責任転嫁禁止）
5. 公平性・非差別
6. データ保護とプライバシー
7. 継続的検証
8. 顧客への誠実な情報開示
9. AI事業者の慎重な選定（10項目評価）
10. ハルシネーション対策（確信度併記）

**DQS A1〜A3軸との連動**（AIコンプライアンス／デジタル運用／データ活用）も明示。

### 望ましい企業資料の新しいストーリー（規範性を持たせる）
```
1. 表紙: 貴社の品質を、選ばれる強みに。
2. なぜ今: AI時代、業界には"守るべき基準"が必要になった
3. ★業界標準の提示: DigiLab AI Code of Practice（10原則）を掲げる
   → 「DigiLab Beautyは、この業界標準を策定・提供する立場」
4. 企業がこれを守るメリット: 信頼の証明・リスク回避・差別化
5. 遵守を客観評価する仕組み: DQS（7視点28項目112点）+ A1-A3連動
6. 3つの評価レベル + 導入の流れ
7. お問い合わせ
```
※ポイント: 「DigiLab Beautyは"基準をつくる側"。企業はその基準を守り、第三者評価で証明する」
　という**ルールメイカーのポジション**を、10原則の実体で裏付ける。

### 法務監修パネル（必ず資料末尾に注記 + 表現チェック）
- **薬機法**: 化粧品56効能リスト外・医療類似の効能効果訴求は不可。
- **景表法**: 「第三者認証」「業界標準」は実体（認証実績・第三者性）が伴って成立。
  実績ゼロのローンチ時は「目指す」等の打消し表現を。成果数値の約束は禁止。
- **特商法**: 月額サブスクは特商法表記・解約条件・運営者情報の明示が必須。
- **個情法**: 会員データ・診断データの利用目的明示と同意取得。要配慮個人情報を問わない設計。
- **ベネフィット・ワン**: 社名・「約140万件」表示は提携契約済み前提（確認済み）。
- **NFT**: 会員証は換金性を持たせない設計（暗号資産該当を回避）。
- ⚠️ これらはAIチェックポイント提示であり弁護士助言の代替ではない。
  **ローンチ前は実弁護士監修が必須。**

## 5. 実装メモ（Next.js移植）

- ルーティング案:
  - `/`（メインLP・タブ2系統）
  - `/line`（2階層目LINEページ）
  - `/welcome`（決済後サンクス）
  - `/business`（企業向けランディング or PDF配布）
- 自己診断はクライアントコンポーネント（`'use client'`）。状態は useState、**localStorage不使用**。
- レーダーチャートは軽量SVGを自前描画（外部ライブラリ不要）。recharts等でも可。
- 公式LINE / Instagram / Stripe Checkout のURLは環境変数化（`.env.local`）。
- デプロイ: Vercel（`digilab-beauty.vercel.app`）。
