# 💄 コスメブレイン (CosmeBrain)

化粧品検定・美肌検定の**有資格者（約180万人）**が、自身の美容知識を
ファイル／記事にして**アップロード・販売**できるマーケットプレイスです。
買う人は「資格保持者が書いた」という安心の中で、正しい美容知識を学べます。

ビジネスモデルのベンチマークは **Brain**（コンテンツ販売＋紹介機能）。

---

## 特長（ビジネスモデルの核）

1. **資格審査ゲート** — 化粧品検定・美肌検定の保有資格を運営が審査・承認。
   承認された人だけが販売者になれる ＝ 買い手は安心して学べる。
2. **知識コンテンツ販売** — 記事本文＋添付ファイルを価格付きで販売。本文は購入者のみ閲覧可。
3. **紹介機能（Brainの肝）** — 購入者は誰でも「自分専用の紹介リンク」を取得でき、
   そのリンク経由で売れると **紹介報酬率(%)** 分の報酬を獲得。
4. **レビュー・ランキング** — 購入者によるレビュー、売れ筋ランキング、カテゴリー検索。
5. **収益ダッシュボード** — 販売収益・紹介報酬・受取残高を可視化。

## 技術スタック

- Python 3 / Flask（既存 DigiLab Beauty の Python・SQLite 構成に準拠）
- SQLite（`schema.sql`）
- Jinja2 テンプレート + 素の CSS（ブランドカラー: 紫 `#8b2fc9` / ピンク `#d946a8` / ゴールド `#ffd700`）

## セットアップ

```bash
cd webapp
pip install -r requirements.txt   # Flask
python seed.py                    # デモ用サンプルデータを投入（DBを作成）
python app.py                     # http://127.0.0.1:5000 で起動
```

`seed.py` を実行しない場合でも、`app.py` 初回起動時に空のDBが自動作成されます。

## 主な画面 / ルート

| ルート | 内容 |
|--------|------|
| `/` | トップ（売れ筋ランキング・新着） |
| `/search` | 検索・カテゴリー絞り込み |
| `/register` `/login` | 登録・ログイン |
| `/certifications` | 資格の申請・状況確認 |
| `/contents/new` | 知識を出品（承認済み販売者のみ） |
| `/c/<id>` | コンテンツ詳細（購入前・レビュー） |
| `/c/<id>/read` | 本文閲覧＋自分の紹介リンク取得（購入者のみ） |
| `/dashboard` | マイページ（出品・購入・資格・収益） |
| `/earnings` | 収益明細 |
| `/admin` | 運営：資格審査（承認/却下） |

## 紹介機能の流れ

1. 購入者がコンテンツを購入 → `/c/<id>/read` で**自分専用の紹介リンク**（`?ref=コード`）を取得。
2. そのリンクから別の人が訪問 → 購入すると、`referral_rate%` が紹介者の残高に加算。
3. 販売者・紹介者の取り分とプラットフォーム手数料（`PLATFORM_FEE_RATE=12%`）は購入時に自動配分。

## 本番化に向けたメモ

- 決済はデモ（記録のみ）。実運用では **Stripe** 等を `content_buy` に接続。
- 資格審査は手動承認。API連携や本人確認(KYC)で強化可能。
- 出金処理（残高 → 銀行振込）の実装が別途必要。
