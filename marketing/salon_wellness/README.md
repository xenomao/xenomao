# サロン起点 予防ヘルスケア 提案資料

カウンセリング型美容サロン(エステ・フェイシャル / 痩身・ボディケア / 脱毛 / ネイル / アイラッシュ / リラクゼーション系)を軸にした、人 × AI ハイブリッド型の予防ヘルスケア事業の提案資料。

## ファイル

| ファイル | 内容 |
|---|---|
| `salon_ai_health_proposal.pptx` | サロン向け提案資料(全13枚) |
| `salon_ai_health_proposal_build.js` | 上記の生成スクリプト(pptxgenjs) |

## 構成(全13枚)

1. タイトル
2. 出発点 ― 髪を切るだけでは、変化は見えない
3. 兆し ― AIの次の主戦場は、ヘルスになった(ChatGPT Health / OpenAI for Healthcare)
4. それでもAIが、構造的に手に入れられない3つのもの
5. 提案 ― サロン起点の予防ヘルスケアモデル
6. 対象 ― カウンセリングが前提の美容サロン
7. サロンが日常的に触れている情報は、すでに「ヘルス」
8. 仕組み ― 3層構造
9. ヘルス領域の最後のピースは、「実世界」と「人」
10. エビデンス基盤 ― Minds型のプロセス
11. サロンにとってのメリット
12. ロードマップと、今回のお願い
13. クロージング

## デザイン

**この資料はLP本体のブランド配色(白基調 × パステルラベンダー)を使っていません。**
BtoB提案での訴求力を優先し、ディープインクネイビー(主調) × ヴァイタルティール × ゴールドの専用配色を採用しています。LP・検定LPの配色は変更していません。

- 主調: `0B1220` / サーフェス: `16233A`, `1E2E49`
- アクセント: ティール `00A896` / `028090`
- 強調: ゴールド `D4A94A`
- ライト面: `F2F5F7` / カード `FFFFFF` + ボーダー `DCE3E9`
- フォント: Yu Gothic(和文) / Arial(欧文・ロゴ)

## 再生成

```bash
cd marketing/salon_wellness
npm install pptxgenjs        # 未インストールの場合のみ
node salon_ai_health_proposal_build.js
```

出力先はスクリプト末尾の `writeFile` で指定しています。差し替える場合はそこを編集してください。
