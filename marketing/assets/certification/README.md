## 再生成の手順

いずれもブラウザで開いてスクリーンショット/印刷するだけで再生成できる(専用ツール不要)。

- **OGP画像**: `ogp_kentei.html` をブラウザで開き、**1200×630** で撮影して `public/kentei/ogp.png` に上書き。カンバスはウィンドウサイズに自動でフィットするため、比率さえ合っていれば構図は崩れない。
- **マーク・エンブレムのPNG**: SVGを任意のサイズで開いて書き出す(推奨1000px・背景透過)。
- **認定証・認証証書**: `{{ }}` のプレースホルダを差し替え、ブラウザの印刷から「PDFに保存」(余白なし・背景グラフィックON)。

Webフォント(Shippori Mincho B1 / Noto Sans JP / Poppins)を参照しているため、**オンライン状態で開くこと**。

## 中央アイコンについて

チェックマーク(✓)は使わない。認証系のマークで最もありふれた記号であり、他制度との差がつかないため。かわりに**ノードグラフ**(結ばれた点)を中核の図像とし、サロン認証は盾、ツール認証は六角形のフレームで区別する。中心の大きなノードは「基準」を、周囲のノードと線は「つながって運用されている状態」を表す。

## カラーバリエーションの使い分け

| 版 | 想定 | 意図 |
|---|---|---|
| ネイビー×ゴールド(正) | 認定証・認証証書・LP・印刷物・報道資料 | 検定/認証の権威性。エンブレム(級位)と揃う |
| スペクトラム(ダーク) | Web・アプリ・SNS・展示会スクリーン | アクア→シアン→バイオレットで「AI」の文脈を明示 |
| ライト | 白地のチラシ・店頭POP・書類の隅 | 白背景で沈まない。線と文字のコントラストを確保 |

> **注意:** 認証マークは「見分けがつくこと」が価値なので、**対外的な正は1つに決めること**を推奨する。3版を並列に使うとマークとしての識別性が落ちる。理事会で正を決め、残りは補助扱い(同一デザイン・色違い)と位置づける。

## 和文と欧文の使い分け(表記のルール)

- **認証マーク(AIセーフサロン / ビューティAIトラスト)は欧文のみ**で構成する。外周は `AI SAFE SALON CERTIFIED` / `BEAUTY AI TRUST MARK` + `DIGILAB BEAUTY`、中央は盾・六角形のフレームに `SAFE` / `TRUST` の一語と**ノードグラフ**(点と線で結んだAIの図像)。店頭やWebで小さく使われるため、和欧混植は可読性と締まりを損なう。
- **和文名称(AIセーフサロン認証 / ビューティAIトラストマーク)はマークの外に置く**。証書・掲示物・Webページ側で「マーク+和文名称+認証番号+有効期限」の組で示す。
- **級位エンブレム(3級/2級/1級)は和文を残す**。こちらは国内の受検者・認定証に向けたもので、`3級` の表記が意味を持つため(意図的な使い分け)。

## 使用ルール(重要)

1. マーク・エンブレムは**有効な認定・認証を受けた者だけ**が、有効期間中に限り使用できる。失効時は速やかに撤去する。
2. 縦横比を変えない。**本フォルダにある3版以外の色に変更しない**。文字を追加・削除しない。
3. 認証マークの掲示には**認証番号と有効期限を併記**する(証書テンプレートは併記済み)。
4. 「安全を保証するもの」と読める表現と併記しない。正しくは「所定の基準への適合を確認したもの」。
5. 詳細な許諾条件は使用許諾規程(整備予定)に従う。商標出願中の名称・図形を含むため、第三者への再配布は不可。
