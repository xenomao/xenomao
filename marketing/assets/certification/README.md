## 再生成の手順

いずれもブラウザで開いてスクリーンショット/印刷するだけで再生成できる(専用ツール不要)。

- **OGP画像**: `ogp_kentei.html` をブラウザで開き、**1200×630** で撮影して `public/kentei/ogp.png` に上書き。カンバスはウィンドウサイズに自動でフィットするため、比率さえ合っていれば構図は崩れない。
- **マーク・エンブレムのPNG**: SVGを任意のサイズで開いて書き出す(推奨1000px・背景透過)。
- **認定証・認証証書**: `{{ }}` のプレースホルダを差し替え、ブラウザの印刷から「PDFに保存」(余白なし・背景グラフィックON)。

Webフォント(Shippori Mincho B1 / Noto Sans JP / Poppins)を参照しているため、**オンライン状態で開くこと**。

## 使用ルール(重要)

1. マーク・エンブレムは**有効な認定・認証を受けた者だけ**が、有効期間中に限り使用できる。失効時は速やかに撤去する。
2. 縦横比を変えない。色を変えない。文字を追加・削除しない。
3. 認証マークの掲示には**認証番号と有効期限を併記**する(証書テンプレートは併記済み)。
4. 「安全を保証するもの」と読める表現と併記しない。正しくは「所定の基準への適合を確認したもの」。
5. 詳細な許諾条件は使用許諾規程(整備予定)に従う。商標出願中の名称・図形を含むため、第三者への再配布は不可。

## 番号体系と照会

- 検定 `C-西暦-連番` / フェロー `F-` / サロン認証 `S-` / トラストマーク `V-`
- 照会ページ: `public/kentei/verify/`(データは `registry.json`)。個人の氏名は掲載しない。
