# ヘルステック・リサーチ（HealthTech Research）

ヘルステック／ヘルスケア分野の**ニュース・IR（決算）・起業リサーチ**を、国内・海外の両面からまとめ・考察するコーナー。DigiLab Beauty のリサーチ機能の一環として、美容業界に隣接するヘルスケア領域の動向を継続追跡する。

## 誰のためのコンテンツか

- **① 動向を手早く知りたい人** … 国内・海外ヘルステックの最新トレンドを毎日キャッチアップ → [`news/`](news/)
- **② ヘルスケア銘柄に投資している人** … 国内海外の上場ヘルスケア企業のIR・決算を解説・考察 → [`ir/`](ir/)
- **③ ヘルスケア分野で起業を考えている人** … スタートアップの資金調達・事業モデル・参入余地をリサーチ → [`startup/`](startup/)

## 3つの柱

| 柱 | ディレクトリ | 更新頻度 | 内容 |
|----|------------|---------|------|
| **ニュース** | [`news/`](news/) | 毎日 | 国内・海外ヘルステックニュースのまとめと一言考察 |
| **IR考察** | [`ir/`](ir/) | 決算シーズン中心 | 国内海外ヘルスケア上場企業の決算解説・投資考察 |
| **起業リサーチ** | [`startup/`](startup/) | 随時 | スタートアップ実録・市場リサーチ・参入分析 |

## 更新運用

- **ニュース**: `news/YYYY-MM-DD_daily.md` の形式で1日1本。国内・海外を並記し、各項目に「なぜ重要か」を一言添える。
- **IR考察**: `ir/YYYYQn_*.md` の形式。決算シーズン（1月・4月・7月・10月）に集中して各社を掘り下げる。
- **起業リサーチ**: `startup/*.md` の形式。テーマ／市場／企業単位で随時追加。
- 既存の日次ニュース収集パイプライン（[`scripts/daily_news_collection.py`](../scripts/daily_news_collection.py)）を将来的にヘルステック・キーワードへ拡張して自動化する想定。キーワード案は本README末尾を参照。
