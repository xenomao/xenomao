# ヘルステック・リサーチ（HealthTech Research）

ヘルステック／ヘルスケア分野の最新動向を、**技術・デバイス・ビューティー連携**の観点でまとめ・考察するコーナー。DigiLab Beauty のリサーチ機能の一環として、美容業界に効く**研究・論文・新発表**を継続追跡する。

> **方針**: 株価・決算・投資の話題には寄らない。**研究／論文／デバイス発表**を軸に、美容の現場・R&Dにつながる情報を洗い出す。

## 誰のためのコンテンツか

- **① 動向を手早く知りたい人** … 国内・海外ヘルステックの最新研究・デバイスをキャッチアップ → [`news/`](news/)
- **② 美容とテクノロジーの接点を知りたい人** … 電子スキン・センサー・LED・成分研究など、サロン／R&Dに効く技術を追う → [`news/`](news/)
- **③ ヘルスケア／ビューティー分野で起業を考えている人** … 技術シーズ・市場・参入余地をリサーチ → [`startup/`](startup/)

## 対象範囲

- **海外**: 米国・欧州に加えて**中国**（CBE／中国化粧品科学技術大会）を継続ウォッチ。
- **技術テーマ**: 電子スキン（e-skin）／柔軟ウェアラブルセンサー／肌の客観計測／ビューティーデバイス（LED・RF・マイクロカレント・レーザー）／スキン・ロンジェビティ／皮膚老化メカニズム（セノリティクス等）／新規成分。
- **主要ソース**: CES／IFSCC（国際化粧品技術者会連盟）／SCCJ（日本化粧品技術者会）／各社R&Dプレスリリース／査読論文（*Adv. Funct. Mater.*, *JMIR* ほか）。
- **ビッグニュース早期キャッチアップ**: 大手のヘルス参入（例: Midjourney）や注目スタートアップの新製品・資金調達（例: Clair Health）を、**企業の一次発信（X＝旧Twitter）**と海外テックメディア（TechCrunch/Fortune/MobiHealthNews等）から早期に拾う。
  - ※X本体は自動取得にログインが必要（未認証は403）。恒久的にX一次情報を自動取得するには **X（Twitter）コネクタの認可**が必要。当面はXの発表を報じるメディア＋X投稿の検索結果で代替。

## 更新運用

- **ニュース**: `news/YYYY-MM-DD_*.md` の形式。国内・海外（中国を含む）を並記し、各項目に「なぜ重要か（📌 ビューティーへの示唆）」を一言添える。
- **起業リサーチ**: `startup/*.md` の形式。テーマ／市場／技術シーズ単位で随時追加。
- 既存の日次ニュース収集パイプライン（[`scripts/daily_news_collection.py`](../scripts/daily_news_collection.py)）を将来的にヘルステック・キーワードへ拡張して自動化する想定。キーワード案は本README末尾を参照。

### 日次自動更新（設定済み）

- **毎朝7:00 JST**、Claude Code のスケジュール実行（Routine）が新規セッションを自動起動し、当日分の `news/YYYY-MM-DD_daily.md` を生成する。
- **研究・論文・デバイス・ビューティー連携**にフォーカスし、株価・決算・投資の話題には寄らない。海外は中国を含める。
- 生成物は `claude/healthtech-daily-YYYY-MM-DD` ブランチにコミットされ、**`main` 向けのPRとして毎日提出**される（レビュー後にマージ）。
- 自動生成は本ファイルの索引には触れない（日次PRのマージ競合回避のため）。索引はまとめ更新時に手動で追記する。
- 停止・時刻変更は Routine の設定（`ヘルステック・デイリーニュース自動更新`）から行う。
