# 美容画像・AI生成コンテンツ 開示基準 v0.1(骨子)

Beauty Image Disclosure Standard v0.1 (Draft)

策定: 一般社団法人デジラボビューティー
版: v0.1(骨子) / 作成日: 2026-08-06
状態: **草案。外部監修・法務レビュー・パブリックコメント前。事業者への適用を求める段階にはない。**

## 0. この基準の立場

### 加工は、悪ではない

本基準は、画像の加工やAIの利用を否定しません。明るさを整えることも、肌を修整することも、AIで素材をつくることも、それ自体は表現の手法です。

問題は別のところにあります。**受け手が、自分の見ているものが何なのかを知らないまま、自分と比べてしまうこと**です。

だから本基準が求めるのは、禁止ではなく **開示** です。

### なぜ必要か

生成AIによって、加工のコストが実質ゼロになりました。かつて技術と時間を要した「存在しない肌」を、いま誰でも一瞬でつくれます。例外だったものが、初期設定になりました。

この変化は、二重の問題を生んでいます。

1. **生活者、とりわけ若年層が、実在しない肌と自分を比べ続けること。** 到達できない基準との比較には出口がありません。
2. **加工しない事業者が、競争上不利になること。** 見分けがつかない市場では、正直な発信ほど見劣りします。誠実さが商売の足を引っ張る構造は、市場の失敗です。

開示は、この両方に同時に効きます。**見えるようになって初めて、誠実さは選ばれる理由になります。**

### 制度上の空白

| 領域 | 適用されるルール |
|---|---|
| 美容医療(医療機関) | 医療広告ガイドライン。加工写真は虚偽広告に該当 |
| 化粧品(メーカー) | 薬機法・業界の適正広告基準 |
| **エステ・美容サロン、個人施術者の発信** | **加工の開示を求めるルールが存在しない** |

医療広告ガイドラインは医療機関を対象とするため、医業ではないサロンの発信には及びません。本基準は、この空白を業界の自主基準として埋めるものです。

> **参考:** フランスは2017年10月、広告画像でモデルの体形を修整した場合に「Photographie retouchée」の明記を義務化。ノルウェーは2021年6月、体型・サイズ・肌をレタッチした広告写真へのラベル表示を義務化しました。
> ※ いずれも応募・公開前に**原典で内容と現行性を再確認すること**(§12)。

## 1. 適用範囲

### 対象とするもの

美容サロン・エステサロン・美容関連事業者および個人施術者が、**自らの事業に関して発信する画像および動画**。

- SNS投稿(Instagram・X・TikTok・LINE公式 等)
- 自社Webサイト・ブログ・LP
- 予約サイト・ポータルサイトへの掲載
- 広告(Web広告・チラシ・看板・DM)
- 提供する印刷物・スライド

### 対象としないもの

- 個人としての私的な投稿(事業の宣伝を目的としないもの)
- 第三者が自発的に投稿したもの(顧客の投稿等)
- 報道・取材記事として第三者が制作したもの
- 医療機関の広告(**医療広告ガイドラインが優先して適用されます**)

### 前提

本基準は、景品表示法・薬機法・特定商取引法・著作権法・肖像権に関する法令の遵守を**前提**とします。本基準を満たすことは、法令遵守を代替しません。

## 2. 用語の定義

| 用語 | 定義 |
|---|---|
| **画像** | 静止画・動画・GIF等、視覚的に提示されるコンテンツ |
| **撮影条件** | 照明、角度、距離、レンズ、姿勢、化粧、着衣など、**撮影時点**で結果に影響する条件 |
| **加工** | 撮影後にデータへ加えた変更。撮影条件の調整は加工に含まない |
| **調整** | 画像全体に一律に適用する、明るさ・コントラスト・色温度・彩度等の変更 |
| **修整** | 被写体の形状・質感・色を部分的または選択的に変更すること |
| **生成** | 生成AIにより画像の全部または一部を新たにつくり出すこと |
| **施術結果画像** | 施術の効果を示す目的で用いる画像(ビフォーアフター、症例写真等) |

## 3. 加工区分 ― 4段階

**判断に迷った場合は、上位の区分(数字の大きい方)を選んでください。** 本基準は、過小申告を防ぐことを優先します。

### L0 ― 無加工

撮影したデータに、視覚的な変更を加えていないもの。

**L0のまま許容される操作:**
- トリミング(切り抜き)、回転、リサイズ、圧縮
- 個人情報・第三者の写り込みを隠すためのモザイク・塗りつぶし

**表記:** `【画像: 無加工】` / `#無加工`

---

### L1 ― 調整のみ

画像**全体**に一律に適用した、以下の変更のみを含むもの。

- 明るさ / 露出
- コントラスト
- 色温度 / ホワイトバランス
- 彩度(全体)
- シャープネス(全体)

**重要:** これらを**部分的に**適用した場合(顔だけ明るくする、肌の部分だけ彩度を下げる等)は L1 ではなく **L2** です。

**表記:** `【画像: 調整のみ】` / `#調整のみ`

---

### L2 ― 修整あり

被写体の形状・質感・色を、部分的または選択的に変更したもの。

**該当する例:**
- 肌の質感の平滑化(いわゆる美肌処理)
- シミ・ニキビ・毛穴・シワ・くま・傷の除去または軽減
- 輪郭・体型・体の一部の形状変更(細く/大きく見せる等)
- 目・鼻・唇など顔のパーツの形状・大きさの変更
- 歯の色の変更、白目の加工
- 髪の量・色の部分的な変更
- 部分的な明るさ・色の調整
- 上記を含むフィルター・プリセットの適用

> ### ⚠ 最重要の注意 ― スマートフォンの美顔モードは L2 です
>
> スマートフォンやアプリの「美顔」「ビューティー」「なめらか肌」「自動補正」等の機能は、**撮影と同時に肌の修整を行っています。** 撮影後に何もしていなくても、これらを有効にして撮影した画像は **L2** に該当します。
>
> 実務上、最も見落とされるのがこの点です。**設定を確認してください。**

**表記:** `【画像: 修整あり】` / `#修整あり`

---

### L3 ― AI生成・合成

生成AIによって作成された、または実在しない要素を含むもの。

**該当する例:**
- 生成AIで作成した画像・動画
- 実在しない人物・モデル(AIモデル)
- 生成AIによる大幅な改変(背景の置換、被写体の生成的な変形、生成塗りつぶし)
- 別の画像との合成により、実際にはない状態をつくり出したもの
- AIによる「将来の姿」「施術後の予測」の生成画像

**表記:** `【画像: AI生成】` / `#AI生成`

## 4. 用途区分と、求められる開示水準

**同じ加工でも、用途によって受け手の解釈が変わります。** 施術結果として示された画像は「事実の記録」として受け取られ、イメージカットは「表現」として受け取られます。したがって求める水準を分けます。

| 用途 | 内容 | 表示 | 許容される最大区分 |
|---|---|---|---|
| **用途A: 施術結果画像** | ビフォーアフター、症例写真、施術の効果を示す画像 | **必須** | **L1まで**(L2・L3は用いない) |
| **用途B: 事業実態を示す画像** | 店内、スタッフ、設備、施術風景 | **必須** | L2まで(L3は用いない) |
| **用途C: イメージ・装飾画像** | 世界観の表現、素材写真、バナー装飾 | **推奨**(L3は必須) | 制限なし |

### 用途Aについての考え方

**施術結果を示す画像に修整(L2)を加えることは、効果の誇張にあたります。** 本基準ではこれを認めません。医療広告ガイドラインが医療機関に対し加工写真を虚偽広告としているのと、考え方をそろえています。

用途AでL1(全体調整)を用いる場合も、**ビフォーとアフターに同一の調整を適用**してください。片方だけを明るくすることは、加工の有無にかかわらず §6 の誤認惹起にあたります。

### 表示単位

- 原則として**投稿単位**で、含まれる画像のうち**最も高い区分**を表示します。
- 画像ごとに区分が示せる媒体では、画像ごとの表示を推奨します。

## 5. 施術結果画像(用途A)の追加要件

加工していなくても、**撮影条件を変えれば効果は演出できます。** 用途Aには以下を求めます。

### 5-1. 撮影条件の統一(必須)

ビフォーとアフターで、以下を可能な限り一致させること。

- 照明(種類・位置・明るさ)
- 撮影角度・距離
- 被写体の姿勢・表情
- 化粧の有無
- 撮影機器・設定

### 5-2. 併記事項(必須)

施術結果画像には、以下を画像と一体で示すこと。

- 施術内容
- 施術回数・期間
- 費用(税込)
- **個人差がある旨**
- 想定されるリスク・副作用・ダウンタイム(該当する場合)

> 医療広告ガイドラインの限定解除要件(施術内容・費用・期間・回数・リスク・副作用を写真と一体で記載)を参考に、サロンの実務に合わせて整理したものです。

### 5-3. 本人の同意(必須)

施術結果画像の使用には、被写体本人からの**書面またはそれに準ずる方法による同意**を得ること。同意には利用範囲・期間・撤回方法を含めること。

## 6. 禁止事項 ― 開示しても認められないもの

以下は、区分を表示していても本基準に適合しません。

### 6-1. 誤認を招く提示

- ビフォーとアフターで撮影条件を意図的に変えること(照明・角度・表情・化粧の作為的な差)
- 他人の施術結果を自店のものとして提示すること
- 施術と無関係な変化(減量・体調・時間経過)を施術の効果として提示すること
- 「加工なし」等の表示を、事実に反して行うこと

### 6-2. 不安を煽る表現

- **AIで生成した「劣化した将来の姿」を提示し、不安を喚起すること**
- 「このままだと〇年後こうなります」型の、根拠のない将来予測
- 特定の外見的特徴を欠陥として扱う表現
- 他者との比較により劣等感を生じさせる構成

### 6-3. 若年層への配慮

未成年を主たる対象とする発信では、外見への不安を喚起する表現を用いないこと。

### 6-4. 効能の逸脱

- 薬機法上認められない効能効果の標榜(化粧品の効能効果の範囲を超える表現)
- 医療行為と誤認させる表現

## 7. AI生成コンテンツの追加規定

画像以外にも、AIによる生成物が事業発信に用いられる場合、以下を開示すること。

| 対象 | 開示の内容 |
|---|---|
| AIモデル(実在しない人物) | 実在しない旨を明示。実在の人物と誤認させないこと |
| AIが生成した口コミ・体験談 | **顧客の声としての提示を禁止。** 実在しない体験を実在の体験として示さない |
| AIが生成した文章(投稿文・記事) | 開示は任意。ただし事実関係は人が確認してから公開すること |
| AIによる肌診断・シミュレーション結果 | AIによる推定である旨と、診断ではない旨を明示 |

### 来歴情報について

将来的に、コンテンツの来歴を記録する技術的枠組み(C2PA / Content Credentials 等)との接続を検討します。ただし **v0.1 では、特別なツールや費用を要する対応を求めません。** 小規模事業者が今日から実行できることを、本基準の要件とします。

## 8. 判断例(FAQ)

現場で実際に迷う場面を挙げます。**この節を、本基準の中で最も重視してください。**

| # | 場面 | 区分・判断 |
|---|---|---|
| 1 | スマホの「美顔モード」で撮影した。撮影後は何もしていない | **L2**。撮影時に修整が入っている |
| 2 | 撮影時にリングライトを当てて明るくした | **L0**。これは撮影条件であり、加工ではない |
| 3 | 写真全体を明るく補正した | **L1** |
| 4 | 顔の部分だけを明るくした | **L2**。部分適用は修整 |
| 5 | ニキビを1つだけ消した | **L2**。範囲の大小は問わない |
| 6 | Instagramのフィルターをかけた | **内容による。** 色調のみなら L1、美肌効果を含むなら L2。判断できない場合は L2 |
| 7 | 背景だけをAIで消した・置き換えた | **L3** |
| 8 | 施術結果の写真を、明るく補正して投稿したい | ビフォーとアフターに**同じ補正**を適用するなら L1 として可。片方だけは不可(§6-1) |
| 9 | 施術結果の写真の肌を少しなめらかにしたい | **不可。** 用途AはL1まで(§4) |
| 10 | イメージ画像としてAI生成の素材を使った | **L3**。用途Cだが L3 は表示必須 |
| 11 | 3年前に撮った写真を今の実績として使いたい | 加工の問題ではない。撮影時期を明示すること。実態と異なる提示は §6-1 |
| 12 | スタッフの集合写真を美肌加工した | **L2**。用途Bなので表示すれば可 |
| 13 | 顧客のビフォーアフターを、顔を隠して投稿したい | モザイクは L0 のまま。ただし §5-3 の同意は必要 |
| 14 | メーカー提供の素材写真を使う | 提供元の区分に従う。不明な場合は提供元に確認し、不明のままなら用途Cに限って使用 |
| 15 | 動画にビューティーフィルターをかけて配信した | **L2**。静止画と同じ扱い |

## 9. 表示の方法

### 表記形式

| 形式 | 例 |
|---|---|
| 正式表記 | `【画像: 無加工】` `【画像: 調整のみ】` `【画像: 修整あり】` `【画像: AI生成】` |
| 略式(SNS) | `#無加工` `#調整のみ` `#修整あり` `#AI生成` |

### 表示位置

- SNS: キャプションの**冒頭または末尾**。他のハッシュタグに埋没させないこと
- Webサイト: 画像の近傍(キャプション・alt属性・注記)
- 印刷物: 画像の近傍または欄外に、判読可能な大きさで

### 表示してはならない態様

- 判読困難な小さな文字
- 大量のハッシュタグに紛れ込ませる
- 一括して「一部加工あり」等とし、どの画像か分からない状態にすること(※投稿単位の最高区分表示は §4 の通り可)

## 10. 本基準が扱わないこと

| 扱わないこと | 理由 |
|---|---|
| 加工の是非そのもの | 本基準は開示を求めるものであり、加工を評価しない |
| 美の基準の定義 | 何が美しいかを本基準は定めない |
| 特定の事業者・投稿の評価 | 本基準は糾弾のための道具ではない |
| 施術・商品の効果の証明・否定 | 本基準は効果について何も主張しない |
| 検出技術による摘発 | 本基準は**自己申告を前提**とする。検出による監視は行わない |

## 11. 適合の表明と認定

- **v0.1 の段階では、適合を表明する制度・認定制度は設けません。** 基準の内容が固まっていないためです。
- 将来的に、基準を継続的に遵守する事業者を認定する制度の設計を予定します(`[構想]`)。
- 認定は、基準の**策定**および講座の**教育**とは担当を分離して運用します(ISO/IEC 17024 を志向)。
