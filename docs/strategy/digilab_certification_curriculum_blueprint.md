> 本書は「何を問い、何を審査するか」を定義する内部標準である。受検者向けの公開範囲は各級の**領域名と配点比率まで**とし、具体的な設問は非公開とする。

---

## 1. 級ごとの到達目標(何ができれば合格か)

| 級/認定 | 到達目標(行動レベル) |
|---|---|
| 3級 | AIに**入れてよい情報と入れてはいけない情報を判別できる**。写真・アカウント・広告表現の基本的な危険を指摘できる |
| 2級 | 日常業務(接客・カウンセリング補助・SNS/LINE・広告文)で、**AIを使った作業を自分で安全に完了できる** |
| 1級 | 店舗・法人単位で **AI利用ルールを策定し、スタッフに教育し、インシデントに対応できる** |
| フェロー | 実際に自店/自社で**ルールを運用し、記録を残し、改善している**ことを証明できる |
| シニアフェロー | 他社の導入・運用を**支援した実績**があり、第三者に説明できる |
| インストラクター | 上記を**教えられる**(講義設計・演習運営・質疑対応) |

## 2. 出題ブループリント

### 3級(無料 / 30問 / 30分 / 正答率70% / 随時・再受検可)

| 領域 | 問数 | 比率 |
|---|---:|---:|
| A. AIに入力してよい情報・ダメな情報 | 7 | 23% |
| B. 顧客カルテ・カウンセリングシートの扱い | 4 | 13% |
| C. 施術写真・ビフォーアフターと肖像権 | 5 | 17% |
| D. Instagram・LINE公式・予約サイトの管理 | 5 | 17% |
| E. AIサービスの規約・アカウント停止リスク | 3 | 10% |
| F. パスワード・APIキー・秘密情報 | 3 | 10% |
| G. AI生成の広告文・投稿文の確認(景表法/薬機法の基礎) | 3 | 10% |

※ 現行の検定LP(`marketing/kentei_lp.html`)の7領域と一致。既存問題集(`public/compliance/`)を**公式練習問題**として接続する。

### 2級(¥9,900 / 50問 / 60分 / 正答率70% / 随時CBT)

| 領域 | 問数 | 比率 | 主な内容 |
|---|---:|---:|---|
| A. 情報の分類と匿名化の実務 | 8 | 16% | 顧客情報の匿名化手順、要約の作り方、伏せるべき属性の判断 |
| B. 接客・カウンセリング補助でのAI活用 | 8 | 16% | 提案文の作成、医療的判断との線引き、断定表現の回避 |
| C. SNS・LINE公式の運用 | 8 | 16% | 投稿文・返信文の生成と確認、権限管理、なりすまし対策 |
| D. 画像・動画の生成と加工 | 7 | 14% | ビフォーアフターの表示ルール、AI加工の明示、同意取得の実務 |
| E. 広告表現(景表法・薬機法・特商法) | 9 | 18% | NG表現の判定、体験談・口コミの扱い、価格・キャンペーン表示 |
| F. AIサービスの規約と契約 | 5 | 10% | 学習利用のオプトアウト、業務利用プラン、アカウント管理 |
| G. インシデントの初動 | 5 | 10% | 誤入力・誤投稿・乗っ取り発生時の手順、報告と記録 |

出題形式: 4択(単一選択)+ 複数選択。**事例文を読ませて判断させる形式を60%以上**にする(暗記では解けない設計)。

### 1級(¥16,500 / 選択60問 60分 + 記述式ケース2問 30分 / 正答率70%かつ記述合格)

| 領域 | 問数 | 比率 |
|---|---:|---:|
| A. AI利用ルールの策定(禁止事項・承認フロー・記録) | 12 | 20% |
| B. スタッフ教育と権限設計(入退社時の権限、教育記録) | 10 | 17% |
| C. データ管理(保存先・保存期間・委託先管理) | 10 | 17% |
| D. 法令対応(個人情報保護法・著作権・広告規制)の実務判断 | 12 | 20% |
| E. ツール選定と契約(利用規約の読み方、ベンダー評価) | 8 | 13% |
| F. インシデント対応と事後改善 | 8 | 13% |

**記述式ケース(各400字程度)**
- ケース1: 「スタッフが顧客の施術写真をAIアプリで加工しSNSに投稿した」— 初動・顧客対応・再発防止策を述べよ
- ケース2: 「自店のAI利用ルールを新規に定める」— 禁止事項・承認フロー・教育・記録の4点を含めて設計せよ

採点は2名の採点者によるルーブリック評価(観点4項目×4段階)。

## 3. フェロー認定 実務課題

提出物(4点):

1. **自店/自社のAI利用ルール**(A4 2枚以内・所定テンプレート)
2. **運用記録**(3ヶ月分。誰が・何に・どのツールを使ったかの記録、教育実施記録)
3. **インシデント想定と対応手順**(1枚)
4. **改善レポート**(運用して分かった問題と、それに対して変えたこと)

審査: ルーブリック(観点8項目×4段階)、合格は各観点3以上。オンライン面談30分で提出物の実在性を確認。
**不合格・条件付き合格を実際に出す。** 全員合格の認定は制度の価値を消す。

## 4. サロン認証 審査チェックリスト(35項目)

判定: 各項目「適合/不適合/該当なし」。**必須項目(★)は全て適合が条件**、それ以外は80%以上の適合で合格。

### I. 体制・ルール(7項目)
1. ★ AI利用に関する文書化されたルールが存在する
2. ★ ルールの周知記録(いつ・誰に)がある
3. AI利用の責任者が明確に定められている
4. 新規ツール導入時の承認フローがある
5. 1級合格者またはフェローが1名以上在籍している ★
6. ルールの最終更新が12ヶ月以内である
7. 外部委託先(制作会社・コンサル)にもルールを適用している

### II. 顧客情報の取り扱い(8項目)
8. ★ 氏名・連絡先・住所をAIサービスに入力しない運用が定着している
9. ★ カルテ・施術記録の原本をAIサービスに貼り付けていない
10. AIに相談する際の匿名化手順が文書化されている
11. 顧客データの保存先と保存期間が定められている
12. 退職者のアクセス権を削除する手順がある
13. 個人情報の利用目的を顧客に明示している
14. 委託先との間で必要な取り決めがある
15. 顧客からの開示・削除請求への対応手順がある

### III. 写真・肖像(5項目)
16. ★ 施術写真の利用について同意を取得している(書面または電子)
17. 同意の範囲(SNS/広告/AI加工の可否)が区別されている
18. AI加工を行った画像はその旨を表示している
19. 顧客が特定できる画像の保存・共有先が限定されている
20. 過去に投稿した画像の削除依頼に対応できる

### IV. アカウント・セキュリティ(7項目)
21. ★ Instagram・LINE公式・予約システムに二段階認証を設定している
22. ★ AIサービスのアカウントを複数人で使い回していない
23. パスワードを共有メモ・紙で管理していない
24. 権限が役割ごとに分けられている
25. APIキー等の秘密情報を公開ページ・チャットに載せていない
26. 端末の紛失時の対応手順がある
27. 利用中のAIツールの一覧を管理している

### V. 広告・表現(5項目)
28. ★ AI生成の投稿文・広告文を人が確認してから公開している
29. 断定的な効果表現(必ず/治る/100%)を避ける基準がある
30. 体験談・口コミの掲載ルールがある
31. 価格・キャンペーンの表示が特商法・景表法に適合している
32. 医療的表現の線引きを担当者が説明できる

### VI. インシデントと改善(3項目)
33. ★ インシデント発生時の連絡先と初動手順が定められている
34. 過去12ヶ月のインシデント(ヒヤリハット含む)を記録している
35. 年1回以上、ルールの見直しを行っている

**ゴールドの追加要件:** 運用ログの実物確認、スタッフへのヒアリング(2名以上)、KPI計測(AI活用の業務時間削減・予約/リピート指標)の実施と提出。

## 5. ベンダー認証(Beauty AI トラストマーク)審査項目

| 分類 | 審査項目 |
|---|---|
| データ | 入力データの学習利用の有無と設定、保存先(国・事業者)、保存期間、削除請求への対応 |
| セキュリティ | 通信・保存の暗号化、権限管理、監査ログ、脆弱性対応体制 |
| 契約 | 利用規約・DPA の明確性、業務利用の可否、再委託の開示 |
| 美容業界特有 | 施術写真・肌画像の扱い、カルテ連携時の設計、医療的表現を生成しない配慮 |
| 表示 | 広告表現、効果の断定、AI生成物であることの表示 |
| 運用 | 障害・インシデント時の通知、サポート体制、日本語対応 |

判定: **適合 / 条件付き適合(是正期限付き) / 不適合**。判定理由の要約を公開レジストリに掲載する(不適合企業名は非公開、適合企業のみ掲載)。

## 6. 問題・基準のメンテナンス

| 対象 | 改訂頻度 | トリガー |
|---|---|---|
| ガイドライン(根拠文書) | 年1回(毎年6月) | 法改正・主要AIサービスの規約変更 |
| 出題(3級/2級/1級) | 年1回 + 随時差し替え | ガイドライン改訂、正答率の異常(90%超/40%未満の設問) |
| サロン認証チェックリスト | 年1回 | 審査での指摘傾向 |
| ベンダー審査項目 | 年1回 | 技術・規約の変化 |

**設問の品質管理:** 各設問に正答率・識別力(上位群と下位群の正答率差)を記録し、識別力が低い設問は差し替える。
