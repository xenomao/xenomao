# 日本化粧品検定ビジネスの構造解体(ティアダウン)

作成: 2026-09-01 / 対象: 一般社団法人日本化粧品検定協会(以下「JCLA」)の検定事業
目的: 同事業の収益構造・成長エンジンを分解し、デジラボビューティーが「AI・DX領域で、より強い版」を設計するための素材とする。

> **出典と精度について**
> 本書の価格・数値は 2026-09-01 時点の公開情報(協会公式サイト、資格ポータル、認定講師の公開記事等)に基づく。改定される可能性があるため、対外資料に転記する際は必ず一次情報で再確認すること。競合の登録商標・教材内容・出題内容は一切利用しない(第6章)。

---

## 1. 全体像 — 「無料の入口」から「教える側」までの5層ファネル

```
[第0層] 無料体験会・無料3級 …… 母数の最大化(のべ176万人規模の受検者プール)
   ↓ 歩留まり
[第1層] 有料検定(準2級/2級/1級) …… 単発売上 + 公式テキストの物販
   ↓
[第2層] 上位資格(特級 コスメコンシェルジュ) …… 高単価講座 + 「資格の使い道」の付与
   ↓
[第3層] 会員(入会金・年会費) …… ストック収益 + コミュニティ・案件供給
   ↓
[第4層] インストラクター/認定教室 …… 受講者が「販売チャネル」に転換
   ↓
[横断] 法人正会員・団体受験・企業タイアップ(660社以上の協賛/サポート)
```

**この事業の本質は「検定を売る事業」ではない。**
検定は入口の商品にすぎず、実体は
(a) 巨大な受検者リストを無料で集め、
(b) 段階的に単価を上げ、
(c) 最終的に受講者を「教える側=集客の担い手」に転換し、
(d) その資格者プールを法人に販売する、
という **人材プール型のプラットフォーム事業** である。

### 顧客1人あたりの積み上げ(LTVの天井)

最長経路をたどった1人が支払う額は概算で以下。

```
2級 8,800 + 1級 13,200(併願なら19,800) + テキスト 約6,000
+ 特級養成講座 29,700 + 入会金 10,000
+ インストラクター 137,500 + 13,200 + 13,200 + 教室登録 33,000
≒ 約 26〜27万円 / 人(初年度)+ 年会費 10,000円/年
```

さらに重要なのは、**第4層に到達した人物が新たな第1層(受検者)を連れてくる**こと。
LTVが約27万円で止まらず、「一人の顧客が集客装置になる」ため、実質的なLTVは青天井に近い。

## 3. なぜ回るのか — 9つの構造メカニズム

1. **権威の借用** — 「文部科学省後援」という第三者権威を看板に置き、資格の信頼性を自社で証明する必要をなくしている。
2. **母数の最大化** — 3級を完全無料・Web随時・何度でも受検可にして、「受検者数のべ176万人」という規模そのものを権威に変換している(数が信頼を生む循環)。
3. **合格の希少性を作らない** — 落とすための試験ではなく、通して次の階段に進ませる試験。合格率が高いことが、次の商品の販売数を最大化する。
4. **学習体験の統制(指定教材)** — 公式テキストを実質必須にすることで、①物販収益 ②出題内容の統制 ③改訂による再購入 の3つを同時に得ている。
5. **「資格の使い道」の後付け販売** — 資格取得後に生じる「で、これをどう活かすの?」という空白に、上位資格・会員コミュニティ・案件・ライター講座などを差し込む。**空白を先に作り、後から埋める**のが利益の源泉。
6. **顧客の販売者化(最重要)** — インストラクター/認定教室は、資格者が自費で講師権を買い、自費で集客し、受検者を協会に供給する構造。協会は営業コストゼロで販路が増える。
7. **ストックの二重化** — 年会費(個人)+ 認定教室更新料 + 法人正会員費で、単発の検定売上に継続収益を重ねている。
8. **B2Bへの転売** — 資格者プールを「採用・手当・社員教育」の文脈で企業に売る(協賛660社以上)。個人から取り、法人からも取る両面市場。
9. **エバーグリーンな無料体験会** — 常時開催の無料ウェビナー(例: コスメライター体験会)で新規リードを絶えず投入し、ファネル全体の流量を維持する。

## 4. 構造的な弱点 — デジラボビューティーが刺せる余地

| # | 弱点 | 何が起きているか | 参入余地 |
|---|---|---|---|
| W1 | **知識の証明どまり** | 記憶した知識を問うだけで、現場で運用できているかは保証しない | 「運用できている状態」を審査・認証する方式に転換できる |
| W2 | **個人単位の資格** | 資格者は個人。事業所(サロン)の安全性は誰も担保していない | **事業所単位の認証**という空白市場が丸ごと空いている |
| W3 | **年2回の会場試験** | 受検の機会が年2回。思い立った日に受けられない | 随時オンラインCBTで機会損失をゼロにできる |
| W4 | **紙のテキスト・改訂は数年単位** | 領域の変化速度が遅い前提の設計 | AI領域は**四半期で陳腐化**するため、更新制の必然性が桁違いに高い |
| W5 | **証明が紙の認定証** | 第三者がその資格を検証する手段が弱い | 公開レジストリ+デジタルバッジで「検証できる信頼」に変えられる |
| W6 | **B2Cの資格販売に閉じている** | 収益源が受検者と法人研修のみ | **ツール提供側(ベンダー)を審査・認証して課金する**第三の市場が空いている |
| W7 | **「資格ビジネス」批判の的になりやすい** | 上位資格の積み上げが高額化し、費用対効果への疑念が生じる | 費用対効果を**数値で示せる設計**(導入前後の指標計測)にすれば差別化になる |

**結論:** 模倣すべきはファネル構造(第0層〜第4層)であり、模倣してはいけないのは「知識検定+紙の権威」という中身である。デジラボは同じ骨格に、**運用認証・事業所認証・ベンダー認証**という3つの上物を載せることで、より強い版を作れる。

## 5. 移植可否の判定

| 要素 | 判定 | デジラボでの扱い |
|---|---|---|
| 無料の入口級 + 常時無料体験会 | ◎ そのまま採用 | 3級を無料・随時に(既存LPを活用) |
| 段階的な級構成 | ◎ 採用 | 3級→2級→1級→上位認定 |
| 上位認定 + 年会費 | ◎ 採用 | 更新制の必然性(AIの陳腐化)を根拠に |
| 講師ライセンス/認定教室 | ○ 採用(条件付き) | 高額な初期費用先取り型にはしない。**成果報酬型のレベニューシェア**へ |
| 指定教材の物販 | △ 形を変える | 紙ではなく**アップデート付きデジタル教材**(年次改訂が価値になる) |
| 官庁後援の看板 | △ 中長期目標 | 短期は業界団体・展示会・企業との連名実績で代替 |
| 資格者の人材プール販売 | ◎ 採用 | AI導入支援の**実務パートナー網**として案件を流す |
| 高額の積み上げ(1人27万円) | × そのままは不可 | 費用対効果を数値で示せない価格設計は取らない(W7) |
| 競合の商標・教材・出題 | × 使用禁止 | 名称・ロゴ・カリキュラム表現は完全に独自で作る |

## 6. 法務上の注意(この解体分析を使ううえでの前提)

- 競合の登録商標(検定名称・資格名称・ロゴ)、公式テキストの記述、出題内容は**一切利用しない**。本書は事業構造(スキーム)のみを分析対象とする。
- 「文部科学省後援」等の後援表記は、実際に承認を得ていない限り使用できない。デジラボの資料で類似表現を用いないこと。
- 資格の効果(就職・収入等)を断定的に表示すると景表法上の優良誤認となりうる。合格実績・導入実績は実数のみを記載する。
