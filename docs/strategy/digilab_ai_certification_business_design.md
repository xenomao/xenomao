## 0. 結論(3行)

1. 化粧品検定型のファネル(無料入口 → 段階的検定 → 上位認定 → 年会費 → 教える側への転換 → 法人販売)は**そのまま骨格として採用する**。
2. ただし中身を「知識の検定」から **「安全に運用できている状態の認証」** に置き換え、対象を **個人だけでなく、サロン(事業所)とAIツール提供者(ベンダー)にも広げる**。これが競合に存在しない3つ目・4つ目の市場になる。
3. デジラボが既に保有する資産(検定LP・診断・コンプライアンス問題集・ガイドライン2026・KPIダッシュボード・会員ポータル)を接続するだけで、**Phase 1 は新規開発をほぼ伴わずに開始できる**。3年目売上の試算は約1億2,300万円(第8章)。

## 1. コンセプト — 何を売るのかを定義し直す

| | 化粧品検定型(従来) | デジラボ版(本設計) |
|---|---|---|
| 売っているもの | 知識を持っていることの証明 | **リスクを管理できている状態の証明** |
| 単位 | 個人 | 個人 + **事業所** + **ツール** |
| 有効期間 | 実質永続 | **1年更新**(AIは四半期で変わる=更新の必然性がある) |
| 証明の形 | 紙の認定証 | 公開レジストリ + デジタルバッジ(第三者が検証できる) |
| 価値の受け手 | 受検者本人 | 受検者 + **その顧客(消費者)** + 取引先企業 |
| 費用対効果 | 説明しづらい | **KPIダッシュボードで導入前後を数値化**できる |

> **一文コンセプト**
> 「AIを使っていい店かどうか」を、消費者と取引先が3秒で確認できる状態をつくる。

「AIを使っています」は誰でも言える。「**安全に使っています**」は第三者が保証しない限り言えない。デジラボはその第三者になる。この立ち位置は、資格販売ではなく **業界インフラ** であり、既存のピッチデッキの主張(「もう一つのAIツールではなくインフラ」)とも完全に一致する。

## 2. 制度の全体構造 — 3レイヤー

```
┌─ L3 ベンダー認証 ───────────────────────────┐
│  Beauty AI トラストマーク(美容向けAIツールの第三者審査)  │  ← 競合に存在しない市場
│  課金相手: SaaS・AIツール・予約/CRMベンダー              │
└──────────────────────────────────────┘
┌─ L2 事業所認証 ────────────────────────────┐
│  AI安全運用サロン認証(スタンダード/ゴールド・年次更新)     │  ← 競合に存在しない市場
│  課金相手: サロン・スクール・美容企業                     │
└──────────────────────────────────────┘
┌─ L1 個人ライセンス ─────────────────────────┐
│  3級(無料)→ 2級 → 1級 → ビューティAIフェロー           │
│  → シニアフェロー → 認定インストラクター                 │
│  課金相手: 個人・スタッフ・法人研修受講者                 │
└──────────────────────────────────────┘
```

L1が母数と権威を作り、L2がストック収益と社会的意義を作り、L3が高単価B2Bを作る。
**L1単体では化粧品検定の劣化コピーにしかならない。L2・L3まで含めて初めて「バージョンアップ」になる。**

### 2.1 既存の名称の統合(先に解決すべき論点)

現在、以下の2系統の名称が併存しており、このままだと制度として説明できない。

- 「美容AIセキュリティ基礎検定 3級」(`marketing/kentei_lp.html` / 公開中)
- 「AI美容カウンセリング技能資格(ビューティーフェロー3級)」(`public/compliance/` 問題集の根拠)

**統合案:**

| 現行 | 統合後の位置づけ |
|---|---|
| 美容AIセキュリティ基礎検定 3級 | **ビューティAIライセンス 3級**(安全とルール)としてそのまま継承。LPは資産として活用 |
| 法令・コンプライアンス問題集 | 3級の**公式練習問題**(無料)として再定義。既に公開済みで改修不要 |
| ビューティーフェロー(3級表記) | 「3級」の呼称を外し、**上位認定「ビューティAIフェロー」** に昇格・吸収。名称の重複を解消 |
| 美容業界AI活用ガイドライン 2026 | 全級・全認証の**出題および審査の根拠文書**(=公式テキストの位置)に格上げ |

## 5. ファネル設計 — 既存資産の接続だけで成立する

```
[入口] サロンAI活用度診断 (/shindan/) ── 無料・10問
   │        既存 ✔
   ▼
[無料] ビューティAIライセンス3級 (/kentei/) + 公式練習問題 (/compliance/)
   │        既存 ✔ (名称の統合のみ)
   ▼
[無料] 月次の無料オンライン体験会(常時開催・エバーグリーン)
   │        既存のセミナー運営体制を流用 ✔
   ▼
[有料] 2級 ¥9,900 / 教材 ¥4,400 / 対策講座 ¥19,800
   ▼
[有料] 1級 ¥16,500 ── ここで「自店のルールを作る」課題に接触
   ▼
[認定] ビューティAIフェロー ¥49,500 + 年会費 ¥13,200
   │
   ├──▶ [L2] 勤務先/自店の サロン認証 ¥55,000 + ¥33,000/年
   │           └──▶ 月次伴走支援(既存事業)へ送客
   ├──▶ シニアフェロー → 案件・監修・登壇の配分
   └──▶ 認定インストラクター → 新規受検者を連れてくる(供給の自己増殖)
```

**転換率の前提(初年度・保守)**
診断→3級 40% / 3級→2級 12% / 2級→1級 30% / 1級→フェロー 25% / フェロー→サロン認証 40%

## 6. 「教える側への転換」の設計(競合の最強メカニズムの改良版)

競合の第4層(インストラクター/認定教室)は、**顧客が自費で販売者になる**という点で極めて強い。デジラボは同じ効果を、より低い炎上リスクで得るために以下とする。

| 論点 | 競合 | デジラボ |
|---|---|---|
| 初期費用 | 約20万円 | ¥66,000 |
| 回収方法 | 受講者が自力で集客 | **協会が講座枠を配分**(公式カレンダーに掲載)+ レベニューシェア |
| 品質管理 | 規定時間のみ | 模擬講義審査 + 受講者満足度4.0未満で改善プログラム |
| 上限 | 無制限 | **地域・枠数の上限を設定**(供給過多で単価が崩れるのを防ぐ) |
| 収入の訴求 | 期待値が独り歩きしやすい | **実績中央値のみを開示**、見込み収入の断定的表示は禁止 |

## 7. 「更新」と「検証可能性」— 競合が持てない2つの武器

1. **更新の必然性**: AIサービスの規約・機能・リスクは四半期単位で変わる。ガイドラインを**毎年改訂**し、更新受講を必須にすることは、受検者にとって合理的であり、協会にとっては年会費・維持料の正当な根拠になる。化粧品成分の知識では、この理屈は成り立たない。
2. **公開レジストリ**: `認証番号 → 有効/失効・種別・有効期限` を照会できるページを公開する。消費者・取引先・メディアが検証できるため、認証マークが「掲示するだけの飾り」にならない。**失効を実際に反映すること**が信頼の担保。
   - 実装: 既存の会員ポータル(`apps/webapp/`)を拡張、または静的JSON + 検索ページで開始できる(Phase 1 では後者で十分)。
   - デジタルバッジは Open Badges 準拠を将来目標とし、初年度は検証URL付きのPNG/PDF認定証で運用。

## 10. 法務・コンプライアンス設計原則

1. **商標を先に押さえる** — 「ビューティAIライセンス」「AI安全運用サロン認証」「Beauty AI トラストマーク」等の名称・ロゴを出願してから公表する。認証マークは**使用許諾規程**(有効期間・表示方法・失効時の撤去義務)とセットで設計する。
2. **後援・権威表記の禁止事項** — 官庁後援は承認がない限り一切表示しない。実績は「◯社導入」「◯名合格」等の**実数のみ**。
3. **景表法・特商法** — 資格取得による就職・収入・集客効果を断定的に表示しない。総額表示、キャンセル・返金規定、事業者情報の明示を申込ページに置く。
4. **薬機法** — 教材・出題の表現自体が広告規制の見本になるため、監修体制を明記する。
5. **個人情報** — 審査で顧客カルテ等の実データを協会に移転しない。受検者情報は利用目的を限定し、既存のプライバシーポリシーを認証事業向けに追補する。
6. **認証の独立性** — 審査基準の全文公開、審査員の利益相反申告、不合格事例の存在。ベンダー認証(L3)では、審査部門と支援・営業部門を分離する。
7. **資格商法と見なされない設計** — 高額な初期費用の先取りを避ける(第6章)、更新の価値を毎年の実体(改訂ガイドライン)で示す、退会・失効の手続きを明示する。

## 11. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 認知不足で受検者が集まらない | ファネル全体が動かない | 展示会・業界団体・既存LINEリスト・提携メディアで3級を無料開放。Phase 1のKPIは売上ではなく**3級受検者数** |
| 認証の価値が消費者に伝わらない | サロン認証が売れない | 認証マークの**消費者向け説明ページ**とレジストリを先に作る。取得サロンのPR支援をセットにする |
| 審査の質のばらつき | 信頼毀損 | チェックリストの標準化(ブループリント参照)+ 審査員2名体制 + 判定記録の保存 |
| 「また資格ビジネスか」という反発 | ブランド毀損 | 初期費用を抑える/成果報酬型/効果をKPIで数値化/不合格を出す |
| 競合(大手検定・SaaSベンダー)の参入 | 先行者利益の喪失 | **事業所認証とベンダー認証で先に標準を取る**。ガイドライン2026を年次で出し続けることが最大の参入障壁 |
| ベンダー認証の利益相反 | 制度全体の信頼崩壊 | 基準の全文公開・部門分離・審査記録の外部監査(将来) |
