### 入会獲得の核心メカニズム

```
セミナー参加者
    │
    ├─ 【当日限定オファー】を提示
    │       └─ 価格は変えずに「特典パッケージ」を当日入会者だけに手渡し
    │           個人: 通常入会金なし → 入会即日に特典4点セット進呈
    │           法人: 初月無料 + 口数は個別相談（当日のみ対応）
    │
    ├─ 【その場で申込書記入】を促す
    │       └─ 申込書 + 振込/決済案内 + 特典説明を1セットで配布
    │
    └─ 【翌日以降フォロー】で迷った人を確保
```

## 入会プラン設計（当日配布用）

### 個人会員

| 項目 | 内容 |
|------|------|
| **月額** | 1,000円（税抜） |
| **当日特典** | 入会特典4点セットを即日プレゼント（下記参照） |
| **決済方法** | その場でクレジットカード / 翌月引き落とし / 翌日振込 |

### 法人会員

| 項目 | 内容 |
|------|------|
| **月額** | 50,000円／1口（税抜） |
| **口数** | 企業規模・利用人数に応じて相談（当日申込者は当日相談優先対応） |
| **当日特典** | 初月無料 + 法人向け特典パッケージ + 個別コンサル枠確保 |
| **決済方法** | 請求書払い（翌月末）/ 口座振替 |

> **補足**: 法人会員は1口50,000円を基本とし、複数口や長期契約の場合は別途ご相談。当日の申込者に限り、代表者と直接口数の相談に応じる時間を設ける。

## ⚡ 絶対に外してはいけない「入会獲得の鉄則5箇条」

1. **申込書を先に配る**: 「後で」は入会しない。コンテンツ終了前に配布開始
2. **時間制限を明示する**: 「今日だけ」「今日13時まで」を繰り返し伝える
3. **社会的証明を使う**: 「すでに〇名がご入会いただきました」をリアルタイムで伝える
4. **決済は当日完了させる**: 「後で振込」は入会率を半分以下にする。その場で決済が理想
5. **迷う人への個別声がけ**: 懇親タイムに迷っている人を見極め、1対1で話す
