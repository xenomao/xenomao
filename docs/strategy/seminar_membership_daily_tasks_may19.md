### 入会獲得の核心メカニズム

```
セミナー参加者
    │
    ├─ 【当日限定オファー】を提示
    │       └─ 通常入会費 → 当日特別価格（例: 30%OFF or 特典付き）
    │
    ├─ 【その場で申込書記入】を促す
    │       └─ 申込書 + 振込案内 + 特典説明を1セットで配布
    │
    └─ 【翌日以降フォロー】で迷った人を確保
```
