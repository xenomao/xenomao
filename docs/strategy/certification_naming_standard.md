# ビューティAI認証制度 名称規程 v1.0

作成: 2026-09-01 / 一般社団法人デジラボビュティ
関連: [`digilab_ai_certification_business_design.md`](./digilab_ai_certification_business_design.md)

本書は、認証事業で使用する**正式名称・略称・英文表記・禁止表記**を定める。以後、LP・教材・SNS・プレスリリース・認定証のすべてで本書の表記に統一する。

---

## 1. 制度の総称

| 区分 | 表記 |
|---|---|
| 正式名称 | **ビューティAI認証制度** |
| 英文 | **Beauty AI Certification Standard** |
| 略称 | **BACS**(バックス)※社内・図表用。対外文書では原則フルネーム |
| 運営 | 一般社団法人デジラボビュティ |

制度は3つの階層で構成する。**「検定」は個人が受けるもの、「認定」は個人に与える上位資格、「認証」は事業所・ツールに与えるもの**と用語を厳密に使い分ける(混用禁止)。

| 旧名称 | 新名称 | 扱い |

| 美容AIセキュリティ基礎検定 3級 | **ビューティAI検定 3級(安全・コンプライアンス基礎)** | 改称。LP・エンブレム・OGPを差し替え |
| AI美容カウンセリング技能資格(ビューティーフェロー3級) | — | **廃止**。「3級」の呼称は L1 の級位に一本化 |
| ビューティーフェロー | **ビューティAIフェロー** | 名称を上位認定に移管(級位表記は付けない) |
| 法令・コンプライアンス問題集 | **ビューティAI検定 3級 公式練習問題** | 位置づけを変更(内容は継承) |

**表記ゆれの禁止**: 「ビューティーAI検定」「Beauty AI検定」「美容AI検定」「AIセーフサロン認定」はいずれも誤り。
**団体名**: 公開ページ上の正式表記は **「一般社団法人デジラボビュティ」**(2026-07 のコミット「Use the official DigiLab Beauty organization name」で全公開ページをこの表記に統一済み)。検定LPは旧表記が残っていたため本改称にあわせて修正した。
※ `CLAUDE.md` と `public/kamata/` には「デジラボビュティ」表記が残存しており、どちらが正かの最終確認が必要(未確認のまま一括置換はしていない)。

過去に発信済みのプレスリリース等(`docs/press/`)は**発信時点の記録として改訂しない**。以後の発信から新名称を用いる。

## 4. 表記ルール

1. 「AI」は半角大文字。「ビューティAI」の間に中黒・スペースを入れない。
2. 級位は半角数字+「級」(例: 3級)。英文は Grade III / II / I。
3. 初出はフルネーム、2回目以降は「本検定」「フェロー」等の短縮可。
4. 認定証・レジストリでは**認定番号**を必ず併記する(体系: 検定 `C-西暦-連番` / フェロー `F-西暦-連番` / サロン `S-西暦-連番` / ベンダー `V-西暦-連番`)。
5. 有効期間のある認証は、掲示・Web表示に**有効期限を必ず併記**する。

---

## 5. 使ってはいけない表現

- 官庁・自治体の**後援・認定・推薦**を、承認を得ずに示唆する表現(「◯◯省後援」等)
- 「国家資格」「公的資格」「免許」など、公的資格と誤認させる語
- 効果の断定(「合格すれば集客できる」「収入が上がる」)
- 他団体の登録商標(検定名・資格名・ロゴ)およびその類似表記
- 「認証取得サロンは安全です」等の**無条件の安全保証**。正しくは「所定の基準に適合していることを確認したものです」
