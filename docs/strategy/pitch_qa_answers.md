# 想定問答集 — 4つの定番質問への回答3パターン(2026-07-14)

ピッチ・助成金審査・行政ヒアリング等で問われる4項目への回答案。
各問い、A=30秒の王道版 / B=論理・データ版 / C=ストーリー版。
※実績に関する言い回しは「試作段階・草案・これから」の現状表記に統一している。盛らないこと。

## 1. 独自性 — なぜあなたがやるのか。独自価値は何か

**A(30秒・王道)**
私たちは「AIを教える団体」ではありません。誠実なサロンをAIで強い店に育て、その到達を第三者として証明する機関です。育成と認証を一体で行う団体は美容業界に存在しません。認証の信用の根拠が「審査の権威」ではなく「うちが育てた店の実例」になる——ここが誰にも真似できない点です。

**B(論理・データ)**
この事業には2つの専門性の交差が必要です。①何が特商法・景表法・薬機法に適合するかを判定できる法令の知見、②AIによる偽装を見抜き、誠実なAI活用を設計できるAIリテラシー。既存の美容団体は①寄りでAIを扱えず、AIベンダーは②のみで誠実さを担保する立場にありません。当法人は法令教材・AIガイドライン・検定体系・診断ツールを自ら開発しており、この交差点に立つ唯一の団体です。

**C(ストーリー)**
きっかけは、技術も人柄も一流なのに、広告のうまい店に埋もれていく現場のサロンを見続けてきたことです。正直にやっている人が損をする——この構造への悔しさが出発点です。生成AIで嘘の見せ方が無限に作れる時代になり、この不公平は放置すれば100倍になります。だからこそ「偽装していないことを証明する仕組み」を、業界の内側を知る私たちが作ります。

## 2. スケーラビリティ — 事業としての成長性

**A(30秒・王道)**
制度は「無料診断 → 講座 → 宣言 → 認証」の階段構造です。この階段は、資本も人手もない一人サロン——子育てをしながら自宅サロンを開くママさんでも、スマホ1台で登れるように設計しました。全国の美容サロンの大半は、こうした小規模事業者です。彼女たちに届く設計であること自体が、市場の広さそのものです。教育は録画化で限界費用ほぼゼロ、認証は年次更新のストック型。そしてこの制度は美容で完結せず、隣にある健康産業へそのまま広がっていきます。

**B(論理・データ)**
成長ドライバーは3つ。①**市場の構造**: 美容業は、働く女性・子育て中の女性が手に職ひとつで開業できる、日本有数の「女性の就業の受け皿」であり、その大半が自宅サロンを含む小規模事業者。店舗網も営業部隊も要らないデジタル教育だからこそ、この無数の点在する市場に追加コストなしで届く。②**認証のネットワーク効果**: 認証店が増えるほど消費者のマーク認知が上がり、マークの価値が上がるほど未取得店の取得動機が強まる自己強化ループ。③**美容から健康産業への拡張**: 「法令×AIの信頼認証」という制度設計は、ネイル・美容室等の隣接業種を経て、セルフケア・予防・介護美容といった健康産業へ移植できる。身体への影響が大きい健康領域ほど「確認された信頼」の必要性は増す——市場は美容の先で、さらに大きくなります。

**C(ストーリー)**
私自身、シングルマザーとして、この業界に生計を立てさせてもらいました。手に職ひとつで、子どもを育てながら働ける——美容は、全国の働く女性にとってそういう命綱の産業です。いま、同じように自宅サロンを開いたママさんたちが、広告のうまい店に埋もれて静かに廃業していきます。この階段は、彼女たちのために設計しました。90分の講座、セルフチェック、宣言——設備投資ゼロ、スマホ1台で、正直さがそのまま看板になる。彼女たち一人ひとりが立ち続けられることが、この業界の継続です。そしてその先で、人をきれいにする仕事から、人を健やかにする仕事へ——美容から健康産業へと橋を架ける。私はこの素晴らしい業界への恩返しとして、この事業をやり抜きます。

## 3. 社会インパクト — 何を解決したいか、どんな社会にしたいか

**A(30秒・王道)**
「正直者が損をしない市場」を作ります。消費者は安心してサロンを選べ、誠実な事業者は広告費でなく技術と接客で選ばれる。エステ業界の長年の消費者トラブル構造を、規制ではなく民間の自主的な仕組みで変えます。

**B(論理・データ)**
エステティック業は資格・許認可のない自由参入市場で、国民生活センターへの相談が長年、役務分野の上位を占めてきました。品質を事前に判別できない市場では価格と広告量が選択基準になり、誠実な事業者ほど埋もれる「逆淘汰」が起きます。私たちは認証と開示によってこの情報の非対称性を解消します。効果は消費者(トラブル予防)、事業者(生産性と公正な競争)、行政(法規制の空白を自主規律で補完)の三方に及びます。

**C(ストーリー)**
生成AIで偽の口コミも盛った施術写真も無限に作れる時代が、もう来ています。放置すれば「何を信じていいか分からない市場」になり、一番傷つくのは消費者と正直な小規模店です。私たちが目指すのは、AIの時代だからこそ「確認された信頼」が通貨になる社会。美容業界でそのモデルを作り、他の業界にも渡したいと考えています。

## 4. 実現可能性 — 精度・実績・顧客見込

**A(30秒・王道)**
構想書・三段階の制度設計・16項目の審査基準・講座カリキュラム・セルフチェックシートまで、制度一式の草案を作成済みです。診断ツールや法令教材などの試作版も公開しています。今後90日で専門家監修と第1期講座を実施し、講座→宣言→試行審査の順に、軽いものから段階的に立ち上げます。

**B(論理・データ)**
実現可能性はリスク設計で担保しています。①認証は確認できる3点(契約・表示・AIの透明性)のみを保証し、施術効果は対象外と明示——過大な保証をしない制度設計。②全教材は弁護士等の専門家監修を経てから提供。③認証はいきなり始めず、講座と宣言で母体を作ってから試行審査(パイロット)で基準の判定可能性を検証。④虚偽宣言の登録抹消・公表ルールを事前に整備。「壊れにくい制度」から逆算して作っています。

**C(ストーリー)**
私たちはこの構想を思いつきで語っていません。セミナー運営の実績と会員サロンの基盤があり、最初の受講者・最初の宣言サロンになる顔ぶれが見えています。そして正直に申し上げます——教材はまだ試作段階(ベータ版)です。だからこそ、監修と試行を経てから世に出す計画にしています。誠実さを証明する制度を、誠実な手順で作る。それが私たちの実現性の証明です。
