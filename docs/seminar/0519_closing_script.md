## ■ よくある抵抗への返し方（スタッフ用）

### 「少し考えさせてください」
```
「もちろんです。ただ1つだけ確認させてください。
今日迷われているのは、内容が合わないからですか？
それとも、タイミングの問題ですか？

（内容の場合）→ 具体的にどの部分が気になりますか？
（タイミングの場合）→ 今日限定の特典をご説明できますか？
```

### 「お金が…」
```
「月¥9,800は、確かに決して安くはないですよね。
ただ、もし1つのキャンペーンがAIで上手くいって
予約が月5件増えたとしたら、それだけで元が取れます。
30日間は全額返金保証がありますので、
まず試してみるという選択肢はいかがでしょうか？」
```

### 「PCが苦手で…」
```
「実は、今の会員の半分以上が最初そうおっしゃっていました。
スマホだけで使えるものからスタートできますし、
月1回のセミナーで一緒にやりながら覚えられます。
難しければ私に聞いてください、というコミュニティがあります。」
```

### 「うちは小さいサロンで…」
```
「むしろ、小さいサロンこそ1人で全部やっている分、
AIが最も効果を発揮するんです。
大きなサロンは人が多い分、変化が遅い。
小規模だからこそ、明日から変えられます。」
```

## ■ 法人向けクロージング（個別相談タイム）

### 法人へのアプローチトーク（休憩中・スタッフ用）
```
「今日は法人プランでいらっしゃいますか？
もしよろしければ、後半の個別相談タイムで
マオと直接お話しいただくことができます。
御社の状況に合わせたプランをその場でご提案します。
ご希望でしたら、今お名前だけ書いていただけますか？」
```

### 法人個別相談での提案トーク（マオさん用）
```
「御社のスタッフ数と、今一番課題に感じていることを
教えていただけますか？

（相手の話を聞く）

なるほど、それであれば…
法人プランは ¥__ /月 で、
まず〇〇から始めるのが一番効果的だと思います。
今日ご決断いただければ、来週から動けます。
いかがですか？」
```
