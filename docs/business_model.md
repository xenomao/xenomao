## 0. 一行サマリー

**「無料AI活用診断」を入口に、大手サロンで旗艦実績を作り、中小サロンへ量産展開する。
運営は非営利型一般社団法人とし、収益事業（コンサル・研修・ツール導入支援）で得た利益を
業界全体の底上げ（公益的活動）へ再投資する。**

---

## 1. ミッションとポジショニング

- **ミッション**: 縮小・人手不足に直面する美容業界に、AI/DXで「生き残りと成長の型」を届ける
- **ビジョン文言（チラシ準拠）**: 美容業界のAI・DXを、ここから始める
- **私たちは何者か**: エステ・ネイル・まつエクに特化した、AI/DX導入の伴走パートナー
- **なぜ社団法人か**: 単独サロンの利益でなく**業界全体の公器**として中立的に推進。
  「特定企業の営業」より「業界団体の支援」の方が、大手・中小双方の信頼を得やすい。

### 裏づけ（前回リサーチの業界事実）
- エステ市場6期連続減 → 2026年度に7期ぶり微増予測（矢野経済研究所）
- 構造的人手不足、AI業務自動化が「最も現実的な解」
- 「何から始めるか不明」「対面の専門性を理解したシステムでないと逆効果」という導入障壁
→ **中立的な"診断"から入る伴走支援**が、この障壁に最も効く。

## 2. 法人設計：非営利型一般社団法人（「非営利性が徹底された法人」型）

### なぜこの型か
2類型のうち、あなたの構想（コンサル・研修で収益を上げる）に適合するのはこちら。
「共益的活動型」は**収益事業が主たる事業だと要件を外れる**ため不適。

### 満たすべき主要要件（要・専門家確認）
| 要件 | 内容 | 設計対応 |
|---|---|---|
| 剰余金不分配 | 定款に剰余金の分配を行わない旨 | 定款に明記 |
| 残余財産の帰属 | 解散時、残余財産は国・地方公共団体・公益法人等へ | 定款に明記 |
| 理事構成 | 各理事＋親族等が理事総数の**1/3以下** | 理事は最低3名、親族集中を避ける（実務上4名以上が無難） |
| 不違反 | 上記に反する決定・実行をしていない | 議事録・運用で担保 |

### 課税の考え方（重要）
- 非営利型は**「収益事業から生じた所得のみ課税」**。会費・寄付は原則非課税の余地。
- ただし**「会費」名目でも、研修・サービスの対価実態があれば収益事業として課税**され得る。
- コンサル/研修/ツール導入支援は**収益事業34業種**（請負業・技芸教授業等）に該当する可能性が高い
  → **課税前提で価格設計**するのが安全。非課税を狙う"純粋会費"とは口座・会計を分離。

## 3. 収益モデル：4階建て（診断フック → 収益事業 → 公益還元）

```
        ┌─────────────────────────────────────────────┐
 入口   │ ① 無料「AI活用診断」（リードマグネット）        │ ← Claudeで生成
        └───────────────┬─────────────────────────────┘
                        │ 診断結果→課題の可視化→自然な提案
        ┌───────────────▼─────────────────────────────┐
 収益   │ ② 導入コンサル（伴走）  ③ スタッフAI研修        │ ← 収益事業（課税）
        │ ④ ツール導入・運用支援（既存ツール統合）        │
        └───────────────┬─────────────────────────────┘
                        │ 利益の再投資
        ┌───────────────▼─────────────────────────────┐
 公益   │ 業界向け無料セミナー/レポート/中小支援          │ ← 社会貢献(非収益)
        └─────────────────────────────────────────────┘
```

### ① AI活用診断（フック）── 入口商品
- **Claudeで診断を生成**：サロンの現状（予約方法・客数・客単価・スタッフ数・悩み）を入力
  → AIが「DX成熟度スコア＋優先改善3点＋想定効果レンジ」を自動レポート化。
- **無料**で提供 → リード獲得。ブログ50本がSEO/SNS流入の受け皿（既存資産と整合）。
- 診断は**中立的な現状把握**であり売り込みでない → 社団法人の中立性とも合致。
- KPI: 診断実施数 → 商談化率 → 受注率（`sales_pipeline`/`kpi_tracking`で計測）。

### ② 導入コンサル（伴走型）── 主力収益
- 診断で見えた課題に対し、業務フロー設計〜ツール選定〜定着支援。
- 価格例（要調整）: スポット診断後の30日伴走 / 90日伴走 のパッケージ。
- 既存テンプレ（200万円トライアル等）は**実績ゼロ段階では高すぎ**。スモール単価から。

### ③ スタッフAI研修 ── スケールする収益
- メール文面の「5,000名育成」ビジョンと整合。オンライン受講で全店同時展開。
- 収益事業（技芸教授業等）に該当の可能性 → 課税前提。
- 会員向け録画アーカイブはCTAテンプレの「セミナー動画アーカイブ」と接続。

### ④ ツール導入・運用支援 ── 既存ツール統合
- 自社で重いプロダクトを作らず、ChatGPT/予約/LINE/HPB等を**束ねて導入支援**（あなたの方針）。
- 将来、診断・研修のSaaS化は選択肢だが**フェーズ2以降**（初期は人的支援で実績作り）。

### 公益的活動（再投資先）
- 中小・個人サロン向け**無料セミナー/月次業界レポート**（CTAテンプレの会員特典と接続）。
- 「利益追求しながら社会に寄与」の"寄与"の実体。非営利型の理念とも一致。

## 4. ターゲット戦略：両建て（大手で実績 → 中小で量産）

| フェーズ | 対象 | 狙い | 主商品 |
|---|---|---|---|
| **Phase 1** | 大手チェーン1〜2社（TBC/ミスパリ/メナード等） | **旗艦実績**を作る。事例化の許諾を得る | ②コンサル（店舗間標準化・全店展開） |
| **Phase 2** | 中堅チェーン | 実績を横展開 | ②③パッケージ |
| **Phase 3** | 中小・個人サロン | **量産**。低単価・高数量 | ①診断→③研修→④ツール |

- **大手**: 意思決定は遅いが、1社の事例が中小100社分の信頼になる。
- **中小**: 診断フックで数を集め、研修・ツールで薄く広く収益化。
- ※営業対象は**有効18社**（CSV19社中「ビー・エスコート」は2024年破産につき除外）。
