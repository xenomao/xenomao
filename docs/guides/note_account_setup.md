## 📋 noteアカウント作成手順

### Step 1: 基本アカウント作成
1. https://note.com/ にアクセス
2. 右上の「会員登録」をクリック
3. 「法人の方」を選択（または「メールアドレスで登録」）
4. メールアドレス: **（DigiLab Beauty用のメールアドレスを使用）**
5. パスワードを設定
6. 利用規約に同意して登録
7. 認証メールのURLをクリックして完了

### Step 2: プロフィール設定
- **noteID**: `digilab-beauty`（推奨）
- **クリエイター名**: `DigiLab Beauty｜ビューティー×テック情報`
- **プロフィール画像**: DigiLab Beautyロゴを使用
- **自己紹介文**:
```
DigiLab Beauty（デジラボビューティー）は、
美容業界のAI・テクノロジー活用を推進する情報メディアです。
海外・国内の最新ビューティーテック情報をお届けします。

🌍 海外ビューティーテック情報
🇯🇵 国内ビューティーテック情報
💡 サロン向けAI活用ガイド

▼ 公式サイト
https://digilab-beauty.com/

▼ 会員登録（無料）
https://digilab-beauty.com/register
```

### Step 3: note pro の検討（推奨）
現在「note pro 最大3ヶ月無料＆スタータープログラム」キャンペーン中（2026年3月31日まで）

**note proのメリット:**
- 予約投稿機能
- 詳細アナリティクス
- 独自ドメイン設定可能
- 複数アカウント管理（最大20人）
- 専任サポート

**申込**: https://note.com/pro にアクセス
