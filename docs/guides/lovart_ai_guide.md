## 🎨 Lovart AIとは

| 項目 | 内容 |
|------|------|
| **サービス名** | Lovart AI |
| **公式URL** | https://lovart.ai / https://lovart.io |
| **種類** | AIデザインエージェント |
| **料金** | 毎日無料クレジット付与（無料プランあり） |
| **商用利用** | ✅ 可能 |

### 主要機能

1. **画像生成**: テキストから高品質な画像を自動生成
2. **動画生成**: マルチモーダルコンテンツ生成
3. **3Dモデル生成**: 製品ディスプレイ用3D画像
4. **テンプレート自動生成**: パンフレット・カタログの自動作成
5. **バッチ生成**: 最大40枚の一括生成
6. **自然言語指示**: チャット形式でデザイン指示

- GPT Image-1
- Flux Pro
- OpenAI o3
- Nano Banana Pro（Google）
- Seedream 4
- Gemini Imagen 4
- Recraft V3
- Ideogram 3.0

## 🚀 セットアップ手順

### Step 1: アカウント作成
```
1. https://lovart.ai にアクセス
2. 「Get Started」をクリック
3. Googleアカウントまたはメールで登録
4. 無料プラン（Freeプラン）を選択
```

### Step 2: DigiLab Beautyブランド設定
```
1. ブランドカラー設定:
   - メイン: #8b2fc9（紫）
   - サブ: #d946a8（ピンク）
   - アクセント: #ffd700（ゴールド）
   - ダーク: #1a0533（ダークパープル）

2. フォント設定:
   - メイン: Noto Sans JP
   - 英語: Inter

3. ロゴ: DigiLab Beauty ロゴをアップロード
```

### Step 3: テンプレート作成
```
以下のテンプレートを事前に作成:
1. SNS投稿用（1080x1080px）
2. Instagramストーリー用（1080x1920px）
3. チラシA4用（2480x3508px）
4. プレスリリース用ヘッダー（1200x630px）
5. セミナー告知ポスター（A3）
```

## 💰 コスト試算

### 無料プランで運用する場合
- **コスト**: $0/月
- **制限**: 1日あたりのクレジット数に制限あり
- **適用**: 小規模運用開始時

### 有料プランで運用する場合
- **コスト**: 要確認（$10〜50/月程度）
- **メリット**: バッチ生成フル利用、高解像度出力
- **適用**: 本格運用時
