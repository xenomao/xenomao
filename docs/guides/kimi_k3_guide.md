# Kimi K3 導入・活用ガイド

Moonshot AI(中国)が2026年7月16日に公開した最新フラッグシップモデル「Kimi K3」の使い方ガイド。
総パラメータ2.8兆(MoE)・コンテキスト約100万トークンのオープンウェイトモデルで、コーディング・長文処理・エージェント用途に強い。

| **日本語** | UI・プロンプトとも対応 |

## 🌐 方法1: アプリ / ブラウザで使う(無料〜)

いちばん手軽な方法。ChatGPTと同じ感覚で使える。

### Step 1: アカウント作成
```
1. https://www.kimi.com にアクセス(またはApp Store / Google Playで「Kimi」を入手)
2. アカウントを作成してログイン
3. チャット画面のモデル選択メニューで「Kimi K3」を選ぶ
   - K3 Max: 高精度の思考(Thinking)モード
   - K3 Swarm Max: 複数エージェント協調モード
```

### Step 2: 使ってみる
- テキスト入力のほか、画像・PDFのアップロードにも対応
- 無料プランあり(1日の利用上限は変動制・非公表)。本格利用は有料メンバーシップ(月額$19〜$199の複数プラン)

## 🔑 方法2: APIで使う(従量課金)

スクリプトや自動化(ニュース収集・メール文面生成など)に組み込む場合はこちら。
**OpenAI互換API**なので、OpenAI SDKがそのまま使える。

### Step 1: APIキーを取得
```
1. https://platform.kimi.ai にアクセス
2. アカウント登録(支払い情報の登録が必要な場合あり)
3. コンソールの API Keys ページで「Create API Key」
4. キー名: 「DigiLab Beauty Kimi」
5. 生成されたキーをコピー
```

### Step 2: 環境変数を設定
PowerShellで以下を実行:
```powershell
# 一時的に設定(現在のセッションのみ)
$env:MOONSHOT_API_KEY = "ここにAPIキーを貼り付け"

# 永続的に設定(推奨)
[System.Environment]::SetEnvironmentVariable("MOONSHOT_API_KEY", "ここにAPIキーを貼り付け", "User")
```

### Step 3: Pythonから呼び出す
```python
from openai import OpenAI
import os

client = OpenAI(
    api_key=os.environ["MOONSHOT_API_KEY"],
    base_url="https://api.moonshot.ai/v1",  # ここを差し替えるだけ
)

resp = client.chat.completions.create(
    model="kimi-k3",
    messages=[
        {"role": "user", "content": "美容サロン向けAI活用ニュースを3行で要約して"},
    ],
)
print(resp.choices[0].message.content)
```

※ K3では `temperature` / `top_p` / `penalty` 系パラメータはサーバー側で固定のため、指定せずに呼び出すこと。

## ⚠️ 利用時の注意(重要)

当団体は「美容AIセキュリティ基礎検定」を提供する立場でもあるため、自らの利用も模範的に。

1. **機密データを入力しない**: 営業リスト・会員情報・DD対象企業リストなど(非公開リポジトリ `digilab-beauty-data` 管理のデータ)は入力禁止。これは他の外部AIサービスと同じ運用ルール
2. **中国拠点の事業者である点**: データの処理・保存場所や規約は変わり得るため、業務利用の前に最新の利用規約・プライバシーポリシーを確認する。APIの入出力はモデル学習に使わない旨が公式に明示されているが、無料のチャットアプリ側は別条件の可能性があるので注意
3. **取引先ポリシーの確認**: 顧客・会員企業によっては中国系AIサービスの利用を制限している場合がある。成果物に使う際は先方ポリシーを確認
4. **セルフホストという選択肢**: オープンウェイトのため、セキュリティ要件が厳しい案件では自社・国内クラウド環境での運用も検討できる(ただし2.8Tパラメータのため相応のGPUが必要)
