### Tier A（最初の3〜5社に絞る）の選定根拠

**Tier A選定の3条件:**
1. 決裁者への接触経路が存在する or 比較的短い
2. 変化へのモチベーションがある（新体制・新しい課題・成長意欲）
3. 月¥100,000〜200,000の予算感が合う規模感

**結論: Tier A = RAYVIS、エルセーヌ、ミュゼプラチナム、ヴァン・ベール、PMK**

理由：
- **RAYVIS**: 年商35億円で直通メール（info@rayvis.jp）が公開されている。中規模で意思決定が比較的速い。
- **エルセーヌ**: 2024年4月に経営主体がTLCに変わった直後。新体制は「旧来のやり方を変えたい」モードが最も高い。
- **ミュゼプラチナム**: 前運営会社が破産し新体制で再建中。「最初からAIで作る」提案が最も刺さる瞬間。
- **ヴァン・ベール**: 山口本社の地方チェーン。本社決裁者との距離が近く、商談スピードが速い可能性。
- **PMK**: 医療連携を行う時点でデータ・コンプライアンス意識が高い。AI導入の文脈が合いやすい。

### 商談フェーズ（Week 9〜16: 8月〜9月）

**商談の設計（30分×2回で契約まで持っていく）:**

#### 第1回商談（30分）: 診断と共感
```
0〜5分:  挨拶 + 「今日は売り込みではなく、現状を聞かせてください」
5〜15分: 診断シートを使って現状ヒアリング
15〜25分: ヒアリング結果から「最も痛い課題」を1つ特定
25〜30分: 「次回、その課題への具体的な解決策をお見せします」
          → 第2回商談の約束を取る
```

#### 第2回商談（45分）: 提案と合意
```
0〜5分:  前回の課題確認
5〜20分: 具体的な解決策の提示（数字で語る）
         「休眠顧客1,000人に対してエージェントで再来店率15%改善すると
          月単価2万円想定で年間¥3,600万円の追加売上」
20〜35分: 3ヶ月お試しプランの説明（¥80,000/月 or ¥150,000/月）
35〜45分: 懸念点のQ&A + 次のステップの合意
```

**価格交渉のルール:**
- 値引きは原則しない（安売りは将来の関係を壊す）
- 値引き要求が出たら「3ヶ月から6ヶ月に延ばす代わりに5%引き」で代替
- 「期待効果の数字」で価格を正当化する（感覚でなく算数）

## 4. テクノロジースタック（現実的な実装設計）

**原則: 最初からSaaSを作ろうとしない。既存APIとノーコードツールで組む。**

### 推奨スタック（開発者なしで構築可能）

```
Layer           ツール              月額コスト     用途
─────────────────────────────────────────────────────────
AI Engine       Claude API          従量課金        分析・レポート・文章生成
Database        Supabase（Free）    ¥0〜¥3,000     SQLiteからクラウドへ移行

Communication   LINE Business API   従量課金        顧客へのアプローチ自動化

Document        Notion              ¥2,000/月       Runbook・クライアント共有
Analytics       Google Looker       ¥0             クライアント向けダッシュボード

**月間インフラコスト上限: ¥30,000（クライアント0社時点）**  
クライアント1社 = Standardプラン¥150,000 → インフラ回収率 500%

### Phase 1で自動化する最初の3つ

**自動化No.1: 月次インテリジェンスレポート**
```
NewsAPI → Claude API → Notion → PDFエクスポート → メール/LINE配信
工数: 0時間（完全自動）
所要構築時間: 3〜5日
```

**自動化No.2: 休眠顧客アプローチメール/LINE**
```

→ Claude API（パーソナライズ文章生成）

→ 反応率をDBに記録
工数: 2時間/月（モニタリングのみ）

```

**自動化No.3: 顧客データ月次分析レポート**
```

## 5. コンテンツ×インバウンド設計（営業依存を段階的に下げる）

**問題**: Tier A 5社へのアウトバウンド営業だけでは、失敗した時のリカバリがない。  
**解決**: コンテンツで問い合わせが来る仕組みを同時に構築する。

### インバウンドファネル設計

```
TOFU（認知）: ブログ記事（既存53本以上のコンテンツを活用）
      ↓
MOFU（関心）: 「AIで動くサロン無料診断」フォーム（Webに設置）
      ↓
BOFU（検討）: 週1回のAIインテリジェンスメルマガ（無料）
      ↓
契約: 3ヶ月お試しプランのクロージング
```

### 既存コンテンツの改修優先度

現在のブログ記事はカテゴリ別に整理されている（global/japan/sales/staff_education等）。
これをSEO観点で**5つの重点テーマ**に集中させる：

| テーマ | キーワード例 | 想定検索者 |
|---|---|---|
| エステサロン AI | 「エステ AI 導入」「サロン ChatGPT」 | 経営者・マネージャー |
| 美容業界 DX | 「美容 DX 事例」「サロン デジタル化」 | 経営者・IT担当 |
| リピート率 向上 | 「エステ リピート率 上げる」 | 経営者・店長 |
| スタッフ教育 AI | 「サロン 研修 AI」「美容師 AI 活用」 | HR・店長 |
| 顧客管理 CRM | 「エステ 顧客管理 システム」 | オペレーション担当 |

### リードマグネット設計

**「エステサロン AI活用度 無料診断（30秒）」**
- Webフォームで10問に答えると「AIで動くサロン成熟度スコア」が即表示
- スコアに応じて「改善提案PDF」を自動送付（Claude APIで生成）
- 同時にメルマガ登録 → 週1回インテリジェンス配信 → 3ヶ月後に有料提案

このリードマグネットはアウトバウンド営業の「事前承認」にもなる。
「先日診断を受けていただいた御社に、個別提案があります」とアプローチできる。
