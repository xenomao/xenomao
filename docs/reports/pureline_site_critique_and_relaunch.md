# pureline-cl.net デザイン批評と「問い合わせが集まるサイト」への再設計

作成日: 2026-07-19
対象: https://pureline-cl.net/ (株式会社ピュアライン)
成果物: `marketing/pureline_lp.html`(新LP・単一HTML)

## 1. 前提: 現サイトの閲覧について

この作業環境からは pureline-cl.net に直接アクセスできなかった。

- 作業環境のネットワークポリシーで同ドメインへの接続が拒否される(CONNECT 403)
- 外部フェッチサービス経由でも、サイト側がHTTP 403を返す(海外IP・bot遮断の可能性)

そのため本批評は、(a) 検索エンジン上の外部シグナル、(b) 同社・代表に関する公開情報、(c) 問い合わせ獲得型LPの一般原則、の3点に基づく。ページ内の個別デザイン要素への言及は、実物のスクリーンショット共有後に追補できる。

## 2. 最重要の発見: デザイン以前に「誰にも見られていない」

**Google検索に pureline-cl.net のページが1件もインデックスされていない**(ドメイン限定検索で0件)。社名・事業・地域・代表者名の組み合わせで検索しても、旧サイトらしき pline459.com は出るが、pureline-cl.net は一切出てこない。

これが意味すること:

- **検索インプレッションは実質ゼロ**とみられる(正確な数値は Google Search Console でのみ確認可能)
- 問い合わせが来ない原因は、デザインの良し悪し以前に「入口がない」こと
- 外部フェッチに403を返している点も要注意。もしGooglebotにも403を返していれば、恒久的にインデックスされない

### 直ちにやるべきこと(サイトの中身と無関係に効く)

1. **Google Search Console にドメインを登録**し、インプレッション・掲載順位の実数を確認する(「インプレッションついてる?」の答えはここで出る)
2. サーバー/WAFの設定で **Googlebot を遮断していないか確認**(URL検査ツールで「公開URLをテスト」)
3. `sitemap.xml` を送信、`robots.txt` と `noindex` の有無を確認
4. 旧ドメイン pline459.com が生きているなら **301リダイレクト**で新ドメインへ統合(評価の引き継ぎ)
5. Googleビジネスプロフィール(松山市)を整備し、サイトへのリンクを設定

## 3. 問い合わせが集まらないサイトの典型課題(批評の観点)

実物確認前でも、この種の会社サイトで問い合わせを逃す典型パターンは以下。新LPはこれらを全て潰す設計にした。

| # | 典型課題 | 新LPでの対策 |
|---|---|---|
| 1 | ファーストビューで「誰の・何の悩みを解決するか」が不明(社名と抽象的な理念だけ) | H1で「サロンの想いを"あなたのブランド化粧品"に」と対象と提供価値を即言 |
| 2 | CTA(問い合わせ導線)が末尾に1つだけ | ヒーロー/悩み/サービス後/最下部+ヘッダー+スマホ追従バーの計6箇所 |
| 3 | 問い合わせの心理的ハードルが高い | 「初回無料」「構想段階の壁打ち歓迎」「しつこい営業なし」「2営業日以内返信」を明記 |
| 4 | 権威性・信頼の根拠が薄い | 代表の25年の現場経験・協会認定講師・登壇実績・登録サロン経営を専用セクションで提示 |
| 5 | 費用・進め方が見えず不安 | 6ステップの開発フロー+費用FAQで「相談したら何が起きるか」を可視化 |
| 6 | スマホ最適化不足 | モバイルファーストのレイアウト+画面下部の追従CTA |
| 7 | SEOの土台がない | title/description/canonical/OGP/構造化データ(Organization・FAQPage)を実装 |

## 4. 新LPの構成(marketing/pureline_lp.html)

1. ヘッダー(常時表示・「無料相談」ボタン)
2. ヒーロー: 提供価値+CTA+安心マイクロコピー
3. 悩み共感(4つ)→CTA
4. 選ばれる3つの理由(現場を知る/伴走型/薬機法〜販売まで)
5. サービス3本柱(開発伴走/販売戦略/事業コンサル)
6. 開発の流れ6ステップ
7. 代表紹介(鎌田麻央・実績と資格)
8. FAQ 6問(費用・ロット・知識ゼロ・勧誘なし)
9. お問い合わせ(mailto・件名プリセット済み)
10. 会社概要 / フッター / スマホ追従CTA

技術面の配慮:

- **JS無効・印刷でも全文が表示される**(演出は `html.js` クラス付与時のみ。既存の鎌田LPは `opacity:0` 初期値のためPrint to PDFで真っ白になる問題があり、その轍を踏まない実装にした)
- 単一HTML・外部依存はGoogle Fontsのみ。どのサーバーにもそのまま置ける

## 5. 公開前に埋めるべき箇所(要確認事項)

- [ ] 所在地の番地表記(現状「愛媛県松山市」まで。特商法対応が必要な販売を行う場合は正式住所・電話の記載を検討)
- [ ] 問い合わせフォーム: mailtoだけでは機会損失が出るため、Googleフォーム等を用意してCTAに追加(HTML内にコメントで挿入位置を用意済み)
- [ ] 公式LINEがあれば第2のCTAとして追加(若年層・スマホユーザーの問い合わせ率が上がる)
- [ ] OGP画像(1200×630)の用意(HTML内コメント参照)
- [ ] 実績数値(伴走件数・開発商品例など)が公開可能なら「選ばれる理由」に追記すると転換率が上がる
- [ ] 現サイトのサーバーへの設置と、上記セクション2のSEO初期設定
