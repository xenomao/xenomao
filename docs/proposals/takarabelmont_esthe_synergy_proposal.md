## 0. エグゼクティブサマリー

タカラベルモント エステ事業部は、**機器・化粧品・空間・教育・経営支援をワンストップで提供する日本エステティックの草分け**であり、1974年開校のエステティックアカデミーに象徴される「教育と現場」の圧倒的な基盤を持つ。一方で、AI・DX・情報セキュリティ・コンプライアンスという**「デジタル安全保障」の領域は、ハード/リアル中心の事業構造の中で相対的に手薄**になりやすい。

DigiLab Beauty は、この空白を埋める**美容業界特化のAI・DX専門機能**(AI活用ガイドライン、AIセキュリティ検定、コンプライアンス教材、サロンAI活用度診断、会員/診断アプリ)を保有する。両者は競合せず、**「リアルの基盤(タカラベルモント)」×「デジタルの知見(デジラボ)」で完全に補完関係**にある。

本提案は、いきなりの大型提携ではなく、**共催セミナー → 認定プログラム共同開発 → 業界標準化**という段階的なプランを提示する。核となる思想は、デジラボのホワイトペーパー『AI時代だからこそ輝く人』が示す**「AIを使い倒し、人間は身体性・関係性に集中する」**という哲学であり、これはタカラベルモントが1973年以来掲げてきた**「人にしかできない、手技と対面の価値」**と正面から一致する。

## 2. シナジー仮説(なぜ組むと強いか)

1. **思想の一致が最大の資産**
   デジラボWPの「AIに委ねる業務(予約・カルテ・分析・SNS)を切り分け、人は身体性・関係性・倫理的判断に全集中する」という役割分担は、タカラベルモントの「手技と対面の価値」を否定するどころか**科学的に補強する**。AIを"敵"ではなく"人の価値を守る道具"と位置づけられる稀有なパートナー。

2. **機器データ × AIの統合余地(DQS A軸)**
   フェイシャル/ボディ/TM3等の計測データを、AIが読解しカウンセリング/セルフケア提案に橋渡しする「テクノロジーと身体性の統合(A3)」は、ハードを持つタカラベルモントとソフト設計を持つデジラボでしか作れない。

3. **AI導入に不可欠な"安全層"を提供できる**
   サロンがAIを使うほど、個人情報・薬機法・景表法・SNSのリスクが増す。デジラボのコンプライアンス教材・AIセキュリティ検定は、タカラベルモントがAI/DXを推進する際の**リスク低減の前提条件**を先回りで用意できる。

4. **教育チャネルの即時活用**
   アカデミーという既存の教育導線に、デジラボのAIカリキュラムを"モジュール"として載せるだけで、全国のサロン人材へ最短距離で届く。ゼロから販路を作る必要がない。

## 3. 協業プラン ―― 4つの共同プロダクト案

### プランA(教育)｜「AI協働エステティシャン」共同認定プログラム
- アカデミーの既存カリキュラムに、デジラボの**AI活用 × 情報セキュリティ × コンプライアンス**モジュールを追加。
- 評価軸に**DQSフレームワーク(H軸/A軸)**を採用し、「手技(H)もAI協働(A)も測る」新時代の認定として共同ブランド化。
- 収益: 受講料/認定料のレベニューシェア、教材ライセンス。

### プランB(安全)｜サロンAI導入の「コンプライアンス・パッケージ」
- タカラベルモントがAIツール/DXを提案する際に同梱する、**AIセキュリティ基礎検定+法令問題集+ガイドライン**の安全教育セット。
- 「機器を入れる=安全教育もセット」という導入標準を作り、他社との差別化に。
- 収益: 検定/教材の卸提供、サブスク型の更新提供。

### プランC(診断)｜「サロンAI活用度診断」を導入コンサルの入口に
- デジラボの診断(全10問)を、タカラベルモントの経営相談/開業支援の**リード獲得・現状把握ツール**として活用。
- 診断結果→機器/化粧品/教育/AIツールの最適提案へと接続する、共同のカスタマージャーニーを設計。
- 収益: 診断ツールのOEM提供、コンサル成約からの紹介フィー。

### プランD(製品)｜機器データ連携AIカウンセリングの共同PoC
- 業務用機器(フェイシャル/ボディ/TM3)の計測データをAIが読解し、**押し売りでない"科学的提案"**を生成する仕組みを小規模で試作。
- WPのDQS A軸(業務最適化・データの批判的読解・身体性との統合)を製品として具現化。
- 収益: 共同開発/将来のライセンス。中長期の目玉。

> 優先順位の推奨: **まずA(教育)とC(診断)から。**既存アセットで即着手でき、投資が小さく、成果が見えやすい。BはAに内包して提示、Dは信頼構築後の中長期テーマ。

## 4. ビジネスモデルの方向性(たたき台)

- **段階1: レベニューシェア型**(共催セミナー・認定・教材)。初期投資を抑え、双方の身銭が最小。
- **段階2: ライセンス/OEM型**(診断ツール・教材をタカラベルモント名義または共同ブランドで提供)。
- **段階3: 共同開発型**(機器データ連携AI)。成果と信頼が積み上がった段階で本格投資。
- 知財: デジラボの教材/検定/DQSフレームワークの権利帰属と共同ブランドの表記ルールを、段階1の契約時に明確化。

## 6. 想定される懸念と対応

| 懸念 | 対応 |
|---|---|
| 大企業と新興団体の規模差・意思決定速度 | 大型提携ではなく**共催セミナー1本から**。小さく始めてリスクを可視化 |
| 既存アカデミー/講師との競合に見えないか | デジラボは**手技を教えない**。AI/DX/セキュリティという"空白の科目"のみ担当する補完役に徹する |
| AI=人の仕事を奪う、という現場の警戒 | WPの思想(AIは人の価値を守る道具)を前面に。**「手技の価値の再定義」**として訴求 |
| 情報の機密性 | 営業DB等の機密は非公開リポジトリで管理。本協業でも情報管理方針を先に合意 |
