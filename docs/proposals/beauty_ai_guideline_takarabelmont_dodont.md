## 0. タカラベルモント様へ ― なぜ、貴社にこそこの基準が必要か

**1973年に機器を用いたエステティックを日本へ紹介して以来、半世紀。** 貴社が積み上げてきた最大の資産は、機器でも化粧品でもなく、**「タカラベルモントが関わるサロンは信頼できる」というブランドそのもの**です。

生成AIは、その信頼を**たった一行の不用意なコピーで崩しうる**リスクを持ち込みました。とりわけ危ういのが、貴社の主力領域です。

- **痩身・ボディ（TM3等）** ―― 「効果」を語った瞬間に、景表法・薬機法の最前線に立つ。AIが最も"やらかす"領域。
- **脱毛** ―― 「永久」「医療級」の一語が、医業類似行為・医療広告の境界を踏み越える。
- **フェイシャル・化粧品** ―― 「シミが消える」等、AIは平然と56効能を超える表現を書く。

これらは**全国のサロン網に広がるほど、事故は1店舗にとどまらず、貴社ブランド全体へ波及**します。だからこそ、機器を導入する入口で「どう語ってよいか」の統一基準を配ることが、**攻めのDXを支える"盾"**になります。

そしてこの基準は、貴社の哲学と矛盾しません。**AIは手技の価値を奪うのではなく、事務・分析をAIに委ねることで「人にしかできない仕事」に集中する時間を生む** ―― これは貴社が半世紀語ってきた「手技と対面の価値」そのものです。

> **私たちの提案は、規制で縛ることではありません。**
> 「ここまでは安全に攻めてよい」という線を明快に引き、貴社が安心してAIを"武器"にできる状態をつくることです。

## 1. 全体原則（この10行だけは全店で共有したい）

1. **効果は「断定」せず「事実」を語る** ― 数値・実績は根拠と出典、体験談は「個人の感想・個人差」を必ず併記。
2. **医療の言葉を使わない** ― 「治る／改善／効く／医療級／永久」はエステ広告では原則NG。
3. **AIの出力は必ず人が最終確認** ― 「AIが書いたから」は免責にならない。責任は事業者が負う。
4. **要配慮個人情報（肌・体・健康）は安易にAIへ入れない** ― 写真・カルテの外部AI投入には同意と線引き。
5. **AI生成であることを、誤認を招く場面では明示** ― 症例風画像・体験談風テキストの偽装は禁止。
6. **56効能を超える化粧品表現を作らせない** ― 「浸透（角層まで）」等の範囲を厳守。
7. **打消し表示は"見える形"で** ― 8ポイントの隅の注記では景表法上足りない。
8. **比較・No.1表現は根拠必須** ― AIが盛った「業界最高」「他社より効く」は優良誤認。
9. **価格・解約・運営者表示を偽らない** ― 特商法。AI生成のLPほど抜け落ちやすい。
10. **困ったら"止める"** ― 迷う表現は出さない。基準はブランドを守るためにある。

## 2. 業務シーン別 ― やってよい／いけない（NG・OK例文つき）

> 各シーンに、貴社の事業に直結する「💡タカラベルモント視点」を付しています。

### シーン① 痩身・ボディ機器（TM3等）の効果表現 ★最重要

| | 内容 |
|---|---|
| ✅ やってよい | 施術の**体感・仕組み・目的**を語る。「巡りにアプローチ」「すっきりとした印象を目指すボディケア」「施術後の"軽さ"を実感される方も（※個人の感想）」 |
| ❌ いけない | **痩身・変化を"結果として断定"**する。「1回で-3cm」「脂肪を減らす」「痩せる機械」「セルライトを分解・除去」 |
| ⚠️ 根拠 | 景表法（優良誤認）／薬機法（機器・化粧品での身体変化の断定は医療機器的表現に接近） |
| 🧪 NG→OK | ❌「AI診断であなたの脂肪燃焼プランを作成、確実に痩せる」→ ✅「AIがカウンセリング内容を整理し、目的に合わせたケアメニューをご提案します（効果には個人差があります）」 |
| 💡 タカラベルモント視点 | **TM3を核にした痩身訴求は、貴社の成長ドライバーであると同時に景表法の最前線。**AIに広告コピーを書かせるほど「-〇cm」「確実に」が混入します。ここを無害化する基準は、痩身事業のアクセルとブレーキを両立させます。 |

### シーン② 脱毛メニューの表現

| | 内容 |
|---|---|
| ✅ やってよい | エステ脱毛＝「**光を用いた"ムダ毛のお手入れ"**」「自己処理がラクになることを目指す」 |
| ❌ いけない | 「**永久脱毛**」「二度と生えない」「医療級」「毛根を破壊」 ―― 医療行為・医業類似行為の領域に踏み込む表現 |
| ⚠️ 根拠 | 医師法・薬機法（医療脱毛との誤認）／景表法 |
| 🧪 NG→OK | ❌「AIが最適な永久脱毛プランを設計」→ ✅「AIがお肌の状態と希望を整理し、無理のないお手入れ計画をご提案」 |
| 💡 タカラベルモント視点 | 全国のサロンでスタッフがAIに接客文を書かせた際、「永久」の一語が最も紛れ込みやすい。**貴社ブランドを冠する店舗ほど、この一語のリスクは重い。** |

### シーン③ フェイシャル・化粧品の効能表現（56効能）

| | 内容 |
|---|---|
| ✅ やってよい | 化粧品の**56効能の範囲**。「うるおいを与える」「肌を整える」「キメを整えて明るい印象に」「（角層まで）浸透」 |
| ❌ いけない | 「シミが消える」「シワが治る」「ニキビを治療」「アトピーに効く」「美白＝漂白的表現」 |
| ⚠️ 根拠 | 薬機法（化粧品の効能効果の範囲＝56効能）／景表法 |
| 🧪 NG→OK | ❌「このケアでシミが消えます」→ ✅「メラニンの生成を抑え、シミ・そばかすを防ぐ（※薬用/医薬部外品の承認範囲内の場合）」「乾燥による小じわを目立たなくする（効能評価試験済みの場合）」 |
| 💡 タカラベルモント視点 | 貴社は化粧品も供給する立場。**メーカー（AI提供者）としての表現責任**が問われる。AIが生成する商品説明・POP・研修資料の効能表現を、56効能で自動チェックする仕組みが効きます。 |

### シーン④ AI肌診断・自動カウンセリング

| | 内容 |
|---|---|
| ✅ やってよい | 「**お手入れの参考情報**」「肌傾向の可視化」として提示し、**最終提案は人（施術者）が確認**して行う |
| ❌ いけない | AIの出力を「**診断**（医療的）」と称する／AI任せで施術やメニューを自動確定する |
| ⚠️ 根拠 | 医師法（診断は医行為）／AIガイドライン（Human-in-the-loop）／個情法 |
| 🧪 NG→OK | ❌「AIが肌を診断し、施術を自動決定」→ ✅「AI分析を"たたき台"に、エステティシャンが確認し、あなたに合うケアをご提案」 |
| 💡 タカラベルモント視点 | まさに**DQSフレームワークのA軸（AIデータの批判的読解）×H軸（人の最終判断）**。AIを"補助"に留め、人の手技・判断を主役に置く設計は、貴社の哲学を製品化したものです。 |

### シーン⑤ 顧客データ（カルテ・肌/体の写真）の取扱い

| | 内容 |
|---|---|
| ✅ やってよい | 利用目的を明示し**同意**を得たうえで、データを**外部送信しない/学習に使わない設定**のツールを選定して活用 |
| ❌ いけない | 肌・体の写真やカルテを、**無料の外部AIに無断で貼り付ける**／要配慮個人情報を同意なく蓄積・共有 |
| ⚠️ 根拠 | 個人情報保護法（要配慮個人情報＝健康情報／利用目的・同意／委託先管理） |
| 🧪 NG→OK | ❌「お客様のビフォーアフター写真を無料AIに入れてSNS文を生成」→ ✅「同意済み・匿名化した情報のみ、法人契約の安全なツールで処理」 |
| 💡 タカラベルモント視点 | 貴社が推奨・提供するシステムは**AI提供者としての委託先管理責任**に直結。「タカラベルモント経由のツールはデータ保護が担保されている」ことが、そのまま導入の決め手になります。 |

### シーン⑥ SNS・広告のAI生成コンテンツ

| | 内容 |
|---|---|
| ✅ やってよい | AIで下書き→**人が事実確認・法令チェック**して投稿。比較・No.1・実績は**根拠と出典**を保持 |
| ❌ いけない | AI生成の**体験談風テキスト・症例風画像を"実例"のように掲載**／根拠なき「業界No.1」「他社より効く」 |
| ⚠️ 根拠 | 景表法（優良誤認・有利誤認・ステマ規制）／AIガイドライン（透明性） |
| 🧪 NG→OK | ❌「AI生成のお客様の声を10件掲載」→ ✅「実在の同意済みお客様の声のみ。AIは文章整形の補助に限定」 |
| 💡 タカラベルモント視点 | 2023年のステマ規制以降、"作られた口コミ"は明確に違反。**全国店舗のSNS運用を統一基準で守ることは、ブランド毀損の予防そのもの。** |

### シーン⑦ エステティックアカデミー（教育教材）のAI利用

| | 内容 |
|---|---|
| ✅ やってよい | AIで教材の**下書き・構成**を作り、講師が監修。**出典・一次情報**を明記 |
| ❌ いけない | AI生成の**効能・成分・法令情報を無検証で教材化**（ハルシネーション）／他者著作物の無断流用 |
| ⚠️ 根拠 | 著作権法／薬機法・景表法（誤った効能の教育は現場のNG表現を量産）／AIガイドライン（継続的検証） |
| 💡 タカラベルモント視点 | 1974年開校のアカデミーが**"正しいAI活用"を教える最初の教育機関**になれる。誤情報を教えれば全国のサロンにNG表現が拡散する――**教育の入口を押さえる意義は、貴社が最も理解している領域**です。 |

### シーン⑧ 全社・全店の運用体制

| | 内容 |
|---|---|
| ✅ やってよい | **社内AI利用ルールの明文化**／利用ログの保存／相談・報告窓口／定期監査／スタッフ検定 |
| ❌ いけない | 現場任せ・属人化。ルールなきまま各店が自由にAIを使う |
| ⚠️ 根拠 | AI事業者ガイドライン（ガバナンス・教育・リテラシー） |
| 💡 タカラベルモント視点 | **統一基準×検定×監査**をセットで持てば、「AIを安全に使えるサロンネットワーク」として対外的に打ち出せます。これは他の機器メーカーが持たない差別化資産です。 |

## 3. NGワード早見表（現場・AIプロンプトに貼る）

| 使ってはいけない | 言い換えの方向 |
|---|---|
| 痩せる／脂肪を減らす／-〇cm確実 | すっきりした印象を目指す／体感には個人差 |
| 永久脱毛／二度と生えない／医療級 | ムダ毛のお手入れ／自己処理がラクに |
| 治る／改善する／効く／治療 | 整える／うるおいを与える／目指す |
| シミが消える／シワがなくなる | （承認範囲で）防ぐ／目立たなくする |
| 100%／必ず／確実に／副作用なし | 個人差があります／体感には差があります |
| 業界No.1／最高／他社より効く | （根拠・出典があるもののみ・調査年月併記） |
| AIが診断・自動で決定 | AI分析を参考に、担当者がご提案 |

> ✅ **実装のツボ**: これをAIツールの「禁止ワード」設定・プロンプトの前提に組み込み、生成段階で弾く。人のチェックと二段構えにする。

## 4. この基準がタカラベルモント様にもたらすもの（3行サマリー）

1. **守り** ― 痩身・脱毛・化粧品という主力領域の景表法・薬機法リスクを、導入の入口で無害化。
2. **攻め** ― 「安全に使える」保証があるからこそ、貴社は自信を持ってAI/DXを提案できる。
3. **旗** ― 業界の草分けである貴社と、この自主基準を"美容業界のAI標準"へ育てたい。

> **AIは、貴社が半世紀かけて磨いた"人の手の価値"を脅かすものではありません。**
> 事務と分析をAIに委ね、その分の時間と誠実さを、目の前のお客様へ。
> ―― その攻めを、コンプライアンスという盾で支えるのが、この基準です。
