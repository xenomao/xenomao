# サロン起点 予防ヘルスケア Phase 1 トライアルキット

カウンセリング型美容サロン(エステ・フェイシャル / 痩身・ボディケア / 脱毛 / ネイル / アイラッシュ / リラクゼーション系)向け、Phase 1 実証の運用資料。

- 関連資料: `marketing/salon_wellness/salon_ai_health_proposal.pptx`(サロン向け提案資料)
- 版数: v0.1 (2026-08)

---

## 0. この取り組みは何であって、何ではないか

**これは「気づきの記録」の仕組みです。**

| これは | これではない |
|---|---|
| 施術前カウンセリングの延長で、体調や生活の変化を記録する | 心の状態を診断・判定するもの |
| 来店ごとの変化を、施術者が把握できるようにする | スクリーニング検査・心理検査 |
| 必要なときに、公的な相談窓口や専門機関へつなぐ | 施術者がカウンセリング(心理的支援)を行うもの |
| 顧客の「気にかけてもらえている」実感を高める | 顧客の悩みを解決してあげるもの |

**Phase 1 では AI を使いません。** 紙または簡易フォームでの記録と、次回来店時の振り返りだけを行い、現場のオペレーションとして無理なく回るかを先に検証します。

## 1. 対象と規模

| 項目 | 内容 |
|---|---|
| 対象サロン | 3〜5店舗(カウンセリングシートの運用が既にあること) |
| 対象顧客 | 各店舗 10〜20 名程度、月1回以上の来店が見込める方 |
| 期間 | 3ヶ月(各顧客につき2〜3回の来店をカバー) |
| 記録手段 | 紙のシート、または Google フォーム等の簡易フォーム |
| 費用 | トライアル期間中は無償 |

**除外条件**: 初回来店の方(比較する前回記録がないため)、本人同意が得られない方、未成年(Phase 1 では対象外とします)。

## 2. 運用フロー(1回の来店あたり)

```
[初回]  同意の説明(1分) → 記録シート記入(2分) → 通常の施術
                                    ↓
                             シートを保管
                                    ↓
[次回]  前回シートを確認(30秒) → 変化を踏まえた声かけ → 記録シート記入(2分) → 通常の施術
                                    ↓
                    大きな変化があれば → セルフケア情報の提供
                    深刻な開示があれば → 第7章のエスカレーション手順へ
```

施術者の追加作業は **1回あたり合計3分以内** を目安にします。これを超える設計は現場で続きません。

## 3. 記録項目

### 3-1. お客様ご自身の記入(5項目)

直近2週間ほどを振り返っていただき、4段階で選択します。**点数を合計しません。** 見るのは「前回からの変化」だけです。

| # | 質問 | 選択肢 |
|---|---|---|
| 1 | 眠れている感じがありますか | よく眠れている / まあ眠れている / あまり眠れていない / ほとんど眠れていない |
| 2 | 疲れは取れていますか | よく取れる / まあ取れる / あまり取れない / ほとんど取れない |
| 3 | 食事は普段どおりとれていますか | 普段どおり / やや変化あり / かなり変化あり / ほとんどとれていない |
| 4 | 気分の浮き沈みを感じますか | ほとんどない / ときどきある / よくある / 常にある |
| 5 | お肌や体調の調子はいかがですか | 良い / まあ良い / あまり良くない / 良くない |

**自由記述欄**(任意): 「最近、気になっていることがあればお書きください」

### 3-2. 施術者による記録(4項目)

施術中に自然に観察できる範囲のみ。詮索はしません。

| # | 観察点 | 記録 |
|---|---|---|
| A | 表情・声のトーン | いつもどおり / やや沈んで見える / 明るい / 気づいた点(自由記述) |
| B | 肌・体調の状態 | いつもどおり / 変化あり(具体的に) |
| C | 会話の様子 | いつもどおり / 口数が少ない / いつもより話される |
| D | 前回からの変化 | 特になし / 気になる変化あり(具体的に) |

## 4. トークスクリプト

### 4-1. 初回:同意をいただくとき

> 「当店では、お客様の体調やお肌の変化をより丁寧に見させていただくために、来店ごとに簡単な記録をとる取り組みを始めています。ご記入は2分ほどで、いつでもおやめいただけます。記録は施術の参考にのみ使わせていただきます。ご協力いただけますでしょうか。」

**言ってはいけないこと**
- 「メンタルヘルスのチェックです」→ 構えさせてしまい、正直な回答が得られません
- 「健康状態を診断します」→ 事実と異なり、医療類似行為と受け取られます

### 4-2. 記入をお願いするとき

> 「よろしければ、こちらに最近の様子をご記入ください。正解はありませんので、なんとなくの感覚で大丈夫です。」

### 4-3. 次回来店時のフィードバック

**変化がないとき**(基本はこれです。無理に何か言う必要はありません)

> 「前回から変わりなく過ごせていらっしゃるようで、よかったです。」

**気になる変化があるとき**

> 「そういえば前回、あまり眠れていないと書いてくださっていましたが、その後いかがですか。」

ポイント:
- **記録を根拠にする**(「なんとなく心配で」ではなく「前回こう書かれていたので」)
- **相手に返す**(こちらの解釈を伝えず、状況を尋ねる)
- **お客様が話したくなさそうなら、それ以上踏み込まない**

### 4-4. セルフケア情報を渡すとき

> 「もしよろしければ、睡眠のことで参考になりそうな情報をお渡ししますね。読むかどうかはご自由で大丈夫です。」

押しつけない、評価しない、宿題にしない。この3点を守ります。

## 5. やってはいけないこと

| 禁止事項 | 理由 |
|---|---|
| 診断名を口にする(「うつかもしれませんね」等) | 医師法上の問題があり、また事実として判断できません |
| 治療法・薬・サプリメントを勧める | 医療・薬機法の領域です |
| 心理的なカウンセリングを行う | 専門的な訓練が必要な行為です |
| 記録内容を他のお客様やスタッフ間で雑談する | 要配慮個人情報の取り扱い違反にあたります |
| 記録内容をSNS・口コミに書く | 同上。事例として使う場合も本人同意が必要です |
| 記入を強く勧める、断りにくい雰囲気を作る | 同意が任意でなくなります |

**迷ったら「聞くだけ、記録するだけ、判断しない」に戻ってください。**

## 6. 個人情報の取り扱い

- 本記録に含まれる心身の状態に関する情報は、個人情報保護法上の **要配慮個人情報** にあたる可能性があります。取得には **本人の明確な同意** が必要です。
- 紙のシートは施錠可能な場所に保管します。持ち出し・撮影は禁止です。
- 事務局(デジラボビューティー)へ共有する際は、氏名・連絡先を除いた **匿名化した形** でのみ行います。
- お客様からの求めがあれば、記録の開示・訂正・削除に応じます。
- トライアル終了後の記録の取り扱い(返却・廃棄・継続保管)を、開始時に決めて同意書に明記します。

## 7. エスカレーション手順

お客様から、**自分を傷つけたい / 消えてしまいたい / 暴力を受けている** といった内容の開示があった場合。

### やること

1. **話を遮らずに聞く。** 「そうだったんですね」「話してくださってありがとうございます」
2. **その場で解決しようとしない。** 助言・励まし・説得はいずれも逆効果になりえます
3. **相談窓口の情報を渡す。** 「こういう窓口があります」と情報として手渡す
4. **施術後すみやかに店舗責任者へ共有する。** 記録には事実のみを書く(解釈を書かない)
5. **緊急性が高いと感じた場合**(いますぐ実行しそうな様子がある等)は、迷わず 119 番通報を検討する

### やらないこと

- 「大丈夫ですよ」「気のせいですよ」と否定する
- 「私も同じ経験があって」と自分の話にする
- 約束を取り付ける、責任を負う言い方をする
- 他のお客様のいる場で話を続ける

## 8. 効果測定(Phase 1 で見るもの)

Phase 1 の目的は「効果があったか」ではなく、**「現場で回るか」** の検証です。

### 主要指標

| 指標 | 目標 | 測り方 |
|---|---|---|
| 記入完了率 | 80% 以上 | 対象来店回数のうち、記録が取れた回数 |
| 施術者の所要時間 | 1回3分以内 | 施術者による自己申告(週次) |
| 2回目以降の継続率 | 70% 以上 | 初回同意者のうち、2回目も記入した割合 |
| 施術者の負担感 | 「負担でない」7割以上 | 月次アンケート(4段階) |

### 補助指標

- 顧客からの「気にかけてもらえている」実感(終了時アンケート、任意)
- 前回比で変化が検出できた件数と、それに対する声かけの実施率
- 想定外の事象(困った場面、判断に迷った場面)の記録 ← **これが最も重要な収穫です**

### やらないこと

- 記録内容から「メンタル不調の人が何人いたか」を集計しない(診断ではないため、その数字に意味はなく、誤解を生みます)

## 9. 3ヶ月のスケジュール

| 週 | 内容 |
|---|---|
| 事前 | 参加サロン確定、同意書の法務確認、シート印刷、施術者向け説明会(60分) |
| 1〜2 | 運用開始。初回同意・初回記録の取得 |
| 3〜4 | 事務局が各店舗へヒアリング(困りごとの吸い上げ)、必要ならシート改訂 |
| 5〜8 | 2回目の来店が発生。フィードバックの声かけを開始 |
| 9〜12 | 3回目の来店。終了時アンケート、施術者インタビュー |
| 終了後 | 振り返り会。Phase 2(認定制度化)の設計へ反映 |
