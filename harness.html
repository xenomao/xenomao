自律開発ハーネス

planner / generator / evaluator — 3役ループで、短い一言から動くものまで

1体制図

23役の担当と禁止事項

planner 企画

✓やること
  • 依頼の曖昧さを自分で確定させる
  • SPEC.md に受け入れ基準を書く
  • TASKS.md に依存順でタスクを並べる
  • 補った前提を明記する
✕やらないこと
  • コードを書く
  • 実装方法・ライブラリを指定する
  • ユーザーに質問する
  • 2回目以降の起動（最初の1回だけ）
出力 SPEC.md TASKS.md

generator 実装

✓やること
  • 未着手タスクを1つだけ選んで実装
  • 技術選定・設計を自分で判断
  • 実際に動かして自己評価を書く
  • 差し戻し時は指摘だけを潰す
✕やらないこと
  • 1回で2タスク以上に手を付ける
  • 自分を pass にする
  • SPEC.md を書き換える
  • 未確認の項目を「OK」と書く
出力 コード *_self_review.md → self_reviewed

evaluator 評価

✓やること
  • headless Chrome で実機を開く
  • スクリーンショットを自分の目で見る
  • 受け入れ基準と照合して pass/fail
  • fail は直し方まで書く
✕やらないこと
  • コードを直して pass にする
  • 受け入れ基準を緩める
  • 画面を見ずコードだけで判定
  • 自己評価の結論を鵜呑みにする
出力 *_eval_n.md スクリーンショット → evaluated(pass/fail)

3つとも対等です。主役を1つ作りません。

動き方は7手 — 1つずつ作って1つずつ検査する
