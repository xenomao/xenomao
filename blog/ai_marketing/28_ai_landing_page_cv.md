## 🤖 AIで作るLP設計の7原則

### ① ファーストビュー（3秒の勝負）

```
AIプロンプト:
「エステサロンのLPファーストビューのキャッチコピーを
5パターン作成してください。

条件:
- ターゲット: 35歳女性、肌の乾燥・くすみ悩み
- サービス: プレミアムフェイシャル
- 特典: 初回5,500円
- 感情を動かす言葉を使う
- 20文字以内」

AI提案:
1. 「もう隠さない。素肌で生きる。」
2. 「-5歳肌、60分で叶えます。」
3. 「鏡を見るのが楽しくなる日。」
4. 「あなたの肌、まだ諦めないで。」
5. 「プロの手で、本来の肌に還る。」
```

### ② ビフォーアフターセクション

AIが**施術データから最も効果が出やすいケースを自動選定**し、説得力のある写真+数値データで構成。

### ③ 社会的証明（口コミ・実績）

AIが口コミの中から**最もCVに貢献するレビュー**を自動選定。

### ④ FAQ（よくある質問）

```
AIプロンプト:
「エステサロンのLPに載せるFAQを10個作成してください。
初めてのお客様が不安に思うことを中心に。」
```

### ⑤ 料金表示の心理学

- アンカリング: 通常価格を先に表示 → 割引価格を大きく表示
- 分割表示: 「1日あたり180円」のような表現

### ⑥ CTA（予約ボタン）の最適化

AIがクリック率を分析し、**最もCVが高いボタンの色・テキスト・配置**を提案。

### ⑦ モバイル最適化

AIがモバイル画面での読みやすさを自動チェック。70%以上のユーザーがスマホから閲覧するため必須。
