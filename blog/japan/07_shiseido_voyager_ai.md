# 資生堂「VOYAGER」が初の製品化に成功 ── 50万件のデータから生まれたAI処方

**カテゴリ**: 国内ビューティーテック情報  
**公開日**: 2026年2月11日  
**執筆**: DigiLab Beauty編集部

## 🚢 50万件の研究データを駆使するAI「VOYAGER」

2026年1月20日、資生堂は処方開発AI**「VOYAGER（ヴォイジャー）」**を活用して開発された**初のユニークな化粧品**の成功を発表しました。

VOYAGERとは、資生堂が100年以上にわたり蓄積した**50万件以上**の研究データ・技術データをAIが統合して分析し、新しい化粧品処方を生み出す「創造型AI」です。

## 🧪 VOYAGERの仕組み

```
従来の製品開発（3〜5年）:
  研究者の経験 → 仮説立案 → 試作 → 評価 → 再試作... 
  → 数百回の試行錯誤

VOYAGER活用（大幅短縮）:
  50万件のデータ → AIが数万通りの処方を生成 
  → 有望な候補を絞り込み → 研究者が評価・選定
```

VOYAGERが革新的なのは、**単なる効率化ツールではなく「創造する」AI**であること。研究者が思いつかなかった新しい組み合わせや、直感に反するが効果的な処方を提案できるのです。

## 🌟 初の成功事例：ミストタイプのサンケア製品

VOYAGER活用で誕生した製品は、以下の特徴を持つミストタイプのサンケア：

- **紫外線防御**: 高いUVカット効果
- **使用感**: みずみずしいテクスチャー（従来のUVケアの「重い」を解消）
- **香り**: AIが最適化したリラクシングフレグランス
- **色彩**: ポジティブな感情を喚起するカラー設計

## 💡 もう一つの注目：AIチャットボット導入

2025年7月から、資生堂は店頭の**パーソナルビューティーパートナー（PBP）**向けに、生成AIを活用したチャットボットも導入しています。

これは顧客向けではなく、**美容部員を支援するためのAI**。商品知識や成分情報を瞬時に検索でき、お客様への情報提供の質とスピードが向上しました。

## 💼 エステ業界への示唆

### ① 「データは100年の財産」
資生堂は100年分のデータを活かしています。エステサロンも**顧客データの蓄積を今日から始めること**が、将来の大きなアドバンテージになります。

### ② 「AIは人を助けるもの」
資生堂のAIチャットボットは美容部員を**置き換える**のではなく、**サポート**するために使われています。エステサロンでも同じ発想で導入を検討しましょう。

### ③ 「創造するAI」の時代
VOYAGERのように、AIが**新しい施術メニューや組み合わせ**を提案する日も近いかもしれません。例えば「この顧客の肌データと過去の施術結果から、最適な施術の組み合わせは…」とAIが提案する未来です。
