# コーセーが挑む「iPS細胞×美容」── 2026年、超パーソナライズ化粧品が現実に

**カテゴリ**: 国内ビューティーテック情報

**執筆**: DigiLab Beauty編集部

## 🧬 あなたの細胞から作る、世界にひとつだけの化粧品

コーセーが、美容業界の**常識を覆す**プロジェクトを進めています。

iPS細胞関連のバイオテック企業**アイ・ピース**、**レジュ**と提携し、顧客自身のiPS細胞を用いた**超パーソナライズ美容商品**の開発に着手。2024年8月から年間30人を対象に実証実験を開始し、**2026年の正式ローンチ**を目指しています。

## 💡 何が革新的なのか

### 従来の「パーソナライズ」との違い

```
レベル1（従来）:
  肌質アンケート → 4〜5タイプに分類 → 既存商品から推薦

レベル2（現在のAI）:
  AI肌分析 → 数十のパラメータ → 最適な既存商品を組合せ

レベル3（コーセーのiPS）:  ★これ！
  あなたのiPS細胞 → DNA/細胞レベルで分析 
  → あなた専用の成分を設計 → 1点モノの化粧品
```

これは「パーソナライズ」の究極形。**あなたの遺伝子・細胞の特性に合わせて、化粧品そのものの設計を変える**という発想です。

## 🔬 技術的な仕組み

1. **iPS細胞の採取**: 少量の血液からiPS細胞を作成
2. **細胞分析**: AIが数千のバイオマーカーを分析
3. **成分設計**: 分析結果から最適な有効成分の組み合わせを算出
4. **製造**: 一人分ずつ個別に製造
5. **評価**: 使用後の肌変化を追跡し、処方を継続的に改良

## 🪞 コーセー銀座のMRメイク体験

もう一つの注目は、高速追従**プロジェクションマッピング技術**を使った**「Mixed Reality Makeup」**。

Maison KOSÉ銀座で提供されるこの体験は：
- 顔の動きにリアルタイムで追従する光学投影
- 実際の化粧品を塗らずに、複数のメイクを瞬時に試せる
- 予約がすぐに埋まるほどの大人気

## 💼 エステ業界への応用シナリオ

### ① 究極のカウンセリング
将来的には、お客様の**遺伝子情報に基づいた施術設計**が可能に。「あなたのDNA的に、この成分が最も効果的」というアドバイスが科学的根拠を持って提供できます。

### ② MRを使った施術シミュレーション
フェイシャル施術の**ビフォーアフターをAR/MRでリアルタイム予測**。「この施術を受けると、3ヶ月後にこうなります」をお客様に見せることで、高額メニューの成約率向上に。

### ③ テクノロジーで「体験価値」を高める
MRメイク体験のように、テクノロジーそのものが**「わざわざ来店する理由」**になる。エステサロンも、AIやARを活用した特別体験を用意することで差別化が可能です。
