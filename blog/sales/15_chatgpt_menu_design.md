## 📋 メニュー表が「売上の入口」だと気づいていますか？

お客様の成約率を左右するのは、施術の質だけではありません。**メニュー表の言葉**が持つ力は絶大です。

同じ施術内容でも、メニュー表の書き方で成約率が**2倍以上**変わることがあります。

## ❌ 売れないメニュー表の特徴

```
❌ よくあるNGメニュー表:

  フェイシャルコース A ... 8,000円（60分）
  フェイシャルコース B ... 12,000円（90分）
  ボディコース C ... 10,000円（60分）
  痩身コース D ... 15,000円（90分）
```

**問題点**:
- 何が違うかわからない
- 選ぶ基準がない
- 安い方を選びがち

## ✅ AIが作る「売れるメニュー表」

ChatGPTに以下のプロンプトを入力するだけで、売れるメニュー表が完成します:

### プロンプト例

```
エステサロンのメニュー表を、以下の心理学的テクニックを使って
書き直してください:

1. アンカリング効果（高額メニューを先に表示）
2. ベネフィット訴求（「何をするか」→「どうなるか」に変換）
3. 松竹梅の法則（3段階の価格帯を設定）
4. 社会的証明（人気No.1、リピート率を表示）
5. 限定性（期間限定、残り枠数を表示）

現在のメニュー:
フェイシャル60分 8,000円
フェイシャル90分 12,000円
ボディ60分 10,000円
```
