# LP同期ループ(ゴール型)

marketing/ の本体と public/ の配信用コピーを完全一致させるためのループ。
「AIが直し、スクリプトが採点する」Actor-Verifier 構成であり、自己判断で完了報告しないこと。

## 停止条件(定量的)

`bash scripts/check_lp_sync.sh` が **終了コード 0**(全ペア一致)。最大試行回数は **5回**。

## 手順

1. `bash scripts/check_lp_sync.sh` を実行し、現状を確認する。
2. 終了コードが 0 なら「全ペア同期済み」と報告して終了。
3. 不一致ペアがある場合:
   - どちらが最新かを `git log --oneline -3 -- <各ファイル>` と diff の内容で判断する。
   - 原則は「直近で意図的に編集された側」が正。新しい側の内容をもう一方へコピーして一致させる。
   - どちらが正か判断できない場合はループを止め、ユーザーに確認する(勝手に上書きしない)。
4. 手順1に戻る。5回試行しても 0 にならない場合は、状況と diff を報告して停止する。

## 同期完了後の注意

- public/ を変更した場合は、コミット・プッシュ後も **gh-pages ブランチに反映されるまで本番に出ない**(CLAUDE.md参照)。同期完了報告の際にこの点を必ず添えること。
- 同期ペアを増やした場合は `scripts/check_lp_sync.sh` の PAIRS 定義にも追記すること。
